# 004 Pico-Lock 4極の検討途中

**発注・通電不可。** 元の004基板を保持した検討途中の候補。電池とモーターを4極のMolex 205338-0004に集約する案で、ピン1 MOTOR_MINUS、2 VBAT（モーター側）、3 GND、4 VBAT（電池側）を想定している。専用ハーネスが必要で、極性・端子番号は組立前にメーカー図面と照合する。

2026-11-27にJ1のDatasheetとDescriptionを回路図に合わせ、KiCad 10.0.8でDRCを再実行した。**違反34件（短絡6件を含む）、未接続1件、回路図との不一致0件**。J1がQ2と近接しており、電源・モーター経路の配置と配線をやり直す必要がある。最新結果は `drc-20261127.json`。3Dモデル、電流経路の発熱、Seeed Fusionでの調達・実装およびハーネス寸法は未確認。

Molexの[Pico-Lockデータシート](https://www.molex.com/content/dam/molex/molex-dot-com/en_us/pdf/datasheets/987650-9061.pdf)では、2.00 mmピッチ、4極、AWG20、全極通電の場合の参考値は5.5 A/極、AWG22は4.5 A/極。30 °C温度上昇を基準とし、PCB配線設計によって温度上昇が変化する。5 Aの設計目標にはAWG20でも余裕が小さく、始動・拘束電流や繰り返し走行時の温度は別途確認が必要。5.5 Aを過電流やピークの許容値とみなさない。

次の作業は、J1/Q2の配置と大電流配線を設計し直すこと、コネクタとケーブルの干渉・3D外形、ピン番号、ERC/DRC/回路図一致、電流・熱と部品調達を確認すること。候補の接続方法は確定していない。
