# ブランチ移動前のECAD保存候補

2026-11-26。006停止時にstashへ保全された `mini4wd-motor-driver` のECADを、004正規版とは別に保存したもの。38フットプリントのPCB、対応する回路図・プロジェクト設定・ローカルライブラリ、MolexとXIAOのSTEPを含む。004ルート直下の22部品版とは異なる回路であり、両者の回路図とPCBを混ぜない。

`mini4wd-motor-driver.kicad_pro` をKiCadで開き、PCBエディターでAlt+3を押す。STEP参照は `${KIPRJMOD}/3dmodels/` を使う。この保存候補を発注対象に選定したという意味ではない。

対応する回路図一式も復元して検査した結果、KiCad 10.0.8のERC・DRC・未接続・回路図パリティはいずれも0件。記録と描画は [今回の確認](../../manufacturing/fusion-resume-20261126/README.md) を参照。

U2は外観用の標準SOT-563モデルへ参照修正した。この環境には既存Q1の標準STEPファイルがなく、L1にもモデルがない。XIAOのSTEP名はMG24であり、Sense下面部品の厳密な干渉検証用モデルとしては未認定。3D画像は機構・電流・熱・実装品質の合格を示さない。

XIAOのSTEP方向は公式端子図と照合してUSB左向きへ修正した。この版ではUSBと左J1が重なるため、機構再配置が必要。元の電気配線とランドは保持している。
