# 004 Pico-Lock 4極・配線候補

2026-11-27。4極コネクタ案の別候補。004正規版と元の `picolock4-20261126` は変更していない。J1を右へ5 mm移動、右端を5.5 mm延長し、外形は60.5 × 21 mmとなった。元の55 × 21 mmに対する車体収納は未確認。

J1のピン1=MOTOR_MINUS、2=VBAT（モーター＋）、3=GND（電池−）、4=VBAT（電池＋）。電池とモーターを1つにまとめる専用ハーネスが必要。極性を回路図とメーカー図面で再確認する。旧配置のB+/B−/M+/M−シルクはF.Fabに移動し、ピンの位置に対応する新しい表示を表面シルクへ追加した。J1の基板端からはみ出すシルク外形もF.Fabへ移した。

旧候補のJ1付近の配線を整理し、自動配線で再接続した。新規配線はVBAT/MOTOR_MINUS/GNDに1.0 mmの指定を与えたが、電流経路には既存の細線やビアも含まれる。1.0 mm指定やDRC合格は5 A連続の許容を意味せず、電流分流、銅厚、ビア、発熱は未評価。メーカーの4極AWG20参考値は5.5 A/極で、始動・拘束の適否も未確定。[Molex仕様](https://www.molex.com/content/dam/molex/molex-dot-com/en_us/pdf/datasheets/987650-9061.pdf)

2026-11-28、J1の電池マイナスから裏面GND面への接続が1本のビアに集中していたため、元の1本に加え穴径0.3 mmのビアを3本並列に追加した。追加後のDRC・未接続・パリティは0件。配線の電流分流・熱容量・実装後の温度は未検証であり、5 A連続を保証しない。裏面はGND銅箔面とビアを使用するため、電池との接触防止に絶縁材と機械的保持が必要。

KiCad 10.0.8で `erc-final.json`: ERC 0件、`drc-final.json`: DRC 0件・未接続0件・回路図パリティ0件。旧コピーの `drc.json`、`drc-20261127.json`、`erc.json` は変更前の履歴である。レイヤー数・回路の詳細検査、コネクタのハーネス・電流熱・Seeed Fusion部品調達・車体寸法は別途必要。

`3d-preview.png` はユーザー提供の `2053380004.stp` をJ1に設定した表示。KiCadのモデルオフセットは (3, -8.09, 0.06) mm、回転0°。3D描画上の端子とパッドの位置を目視で照合した。相手側ハウジング・ケーブルは描画しておらず、車体との干渉や抜き差し余地は未確認。以前の直方体 `J1_PICOLOCK_ENVELOPE_APPROX.step` は参考として残し、使用していない。
