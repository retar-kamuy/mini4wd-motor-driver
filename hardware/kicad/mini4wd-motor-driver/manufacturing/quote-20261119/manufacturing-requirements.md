# 製造・実装条件（見積依頼用）

この条件の業者受入は未確認。標準工程で満たせない条件は、価格・納期・設計変更の要否を回答する。CAD/Gerberの無断変更・代替部品は認めず、変更案を事前に提示する。

| 項目 | 見積基準・要求/確認事項 |
|---|---|
| 用途 | 個人用モータードライバーの初回試作。完成品2/5/10枚を別見積、基板余剰/MOQを別記 |

| ビアめっき | 電流予算の仮定は20µm。**穴壁銅20µm以上**を見積基準とし、最小値と検査方法を回答。CAD穴径0.3/0.4mmと完成穴径の対応/公差を照合 |
| 2oz案 | 主経路の低損失案として別見積可。0.127mm配線/隙間があるため現Gerberへの2oz適用を自動承認しない。工程DFM回答後に判断 |
| 表面・はんだ | 見積基準はENIG、緑ソルダーマスク、白シルク、鉛フリー実装。膜厚・リフロー/洗浄条件と変更案を回答。これは受入済み仕様ではない |
| 部品面 | 全38品はF.Cu/Topのみ。B.Cu/Bottomは電池側、部品なし、全82ビア裏面テント。B.Mask開口なしをCAMで確認 |
| Q1パッド内ビア | `assembly/q1-pad-vias-mm.csv`の6個。非導電樹脂充填＋銅キャップ/平坦化など、吸い込みと平坦性を管理できる工程を提示。適用規格/工程、充填材、平坦性、検査と追加費を回答。テントだけで代用しない |
| その他ビア | 0.6/0.3mm 49個、0.8/0.4mm 33個。XIAO投影内の表裏テントを保持。Q1穴埋め対象は別工程 |

| MCU1 | **Seeed Studio102010610、XIAO MG24 Sense、ヘッダなし**をcastellated SMT実装。102010608/非Sense/ピンヘッダ品へ置換不可。モジュールの二次リフロー可否、カメラ/マイク等の工程、供給包装、吸着/支持・手動工程を業者確認。利用者の手はんだを前提にしない |
| 全品供給 | `bom-turnkey.csv`の正確なメーカー/MPNで一括調達・実装を基本見積。支給が必要なら型番・数量/余剰・包装・受入条件を回答。工場内手作業も工数と検査を明示 |
| 固定型番 | U101はLTC6994IS6-2#TRMPBFの**-2**、U104はTI UCC27524ADR。類似品/別サフィックス/メーカー変更を無断で行わない。BOM値の(candidate)は設計評価状態で、自由代替を意味しない |
| BOM例外 | R105/R106はサブµsゲートパルス能力を要確認、電流検出抵抗ではない。R101表示0.5%に対し指定MPNは0.1%品。MPNを調達識別とする。MLCCの同容量別型番への変更は実効容量を再評価 |
| CPL/方向 | mm、絶対原点、Y反転、Top視点。部品ライブラリ原点/回転、D1/D2 cathode側、Q1/Q2 pin1、MCU端子名、コネクタ極性と向きを全品プレビューで照合。汎用角度オフセットを一括適用しない |
| 検査 | PCB電気検査はGerberとIPC照合、実装AOI/極性・ブリッジ・SMT接合、Q1/Q2底面接合のX-ray可否/費用を回答。洗浄・外観写真を提示。MCU書込み/モーター接続通電試験は本見積の標準範囲に含めず、実施提案は試験条件を事前合意 |
| 見積内訳 | PCB/完成品枚数、部品正味数量とMOQ/ロス/余剰、調達費、段取り、ステンシル、パネル/キャリア、充填/キャップ、実装/手作業/検査、送料/税、納期、余剰返却、見積有効期限を提示 |
