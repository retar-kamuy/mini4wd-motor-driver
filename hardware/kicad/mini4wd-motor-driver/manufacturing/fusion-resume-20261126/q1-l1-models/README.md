# 004の欠落3Dモデル対応

2026-11-26。正規PCBの22フットプリントを監査し、既に表示対応したQ2/U2等を除き、Q1の参照先欠落とL1のモデル未設定が残っていた。今回これらを補い、22部品すべてに存在するモデル参照が付いた。電気回路、ネット、ランド、配置、配線、外形、設計規則は変更せず、モデル要素を除いたS式が全一致することを確認した。

## Q1: SiSS64DN-T1-GE3

[KiCad公開MR !813](https://gitlab.com/kicad/libraries/kicad-packages3D/-/merge_requests/813)の `Vishay_PowerPAK_1212-8_Single.step` を取得し、プロジェクト内3dmodelsへ保存した。MRはPending reviewerの未マージ提案であり、KiCad現行標準やメーカーが個別型番を認定したモデルと扱わない。元のライセンス/著作権ヘッダーは保持した。

STEPのBREP頂点範囲から3.30×3.25×0.80mmを得た。[Vishay PowerPAK1212-8S図63919](https://www.vishay.com/docs/63919/ppak1212-8s.pdf)の外形3.20〜3.40mm角、高さ0.67〜0.83mm内。端子ピッチ0.65mmと端子1側を現フットプリントに照合し、回転0・倍率1・オフセット0で参照。上面・斜視で本体と端子の表示を確認した。頂点範囲は厳密な曲面/公差/干渉解析ではない。

## L1: XEL4030-102ME の最大外形

正式な詳細モデルは取得できていない。Coilcraft公式Altium ZIPの取得はHTTP403、適合CADサイトのダウンロードはログインを要した。形が異なるXAL4030を代用せず、メーカー外形図に基づく**最大外形のみの概形STEP**を作成した。

[メーカー外形図](https://www.coilcraft.com/getattachment/53a07e14-2bbc-455d-8f84-80e6f9e135be/xel4030d.gif?lang=en-US)を取得・目視し、平面4.0±0.3mm角、-102の実装高さ最大3.10mmを確認した。概形は **4.3×4.3×3.1mm** の直方体。端子、面取り、印字、巻線詳細は省略している。メーカー認定モデルや実物の精密外観ではなく、最大外形を表示するためのもの。

- ファイル: `3dmodels/L1_XEL4030_102_MAX_ENVELOPE.step`
- 再生成: `python3 3dmodels/build_l1_envelope.py` （パスはプロジェクト起点）
- 正式STEP入手後はPCBとboard-routedのL1モデル参照を交換できる。
