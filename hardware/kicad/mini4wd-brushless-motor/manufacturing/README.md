## 証拠インベントリ

リポジトリルートで実行:

```sh
python3 tools/pcb/audit_spec005_release.py --output specs/005-mini4wd-brushless-motor/evidence/release-inventory.json
```

入力ファイルの有無とSHA-256、検査証拠・revision製造ファイルの有無を記録する。ファイル内容の適合を判定しない。不足があると終了コード2を返す。終了コード0でも製造承認ではなく、設計レビュー/ネイティブ検査/業者DFM/利用者承認が必要。

JLCPCBの設計ルール・組立制約は見積時に[公式製造能力](https://jlcpcb.com/capabilities/pcb-capabilities)と対象サービスで再確認する。最小寸法だけで電流/放熱/組立適合を判断しない。上表は発注前に揃える成果物であり、注文・支払い・外部提出を行った記録ではない。
