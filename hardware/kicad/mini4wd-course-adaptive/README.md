# 006 車載ブラシレス制御 PCB 初版候補

2026-11-22。正本は `mini4wd-course-adaptive.kicad_sch` と同名プロジェクトです。市販シャーシの四輪駆動を残し、MCT8316ZRでHall付きROCKET-RC MINI 1525 5500KVを電流制限付きで評価する初版設計。XIAO MG24 SenseのBLE、車載IMU、内蔵メモリーを使います。初版の速度、実機温度、VZへの収まりは実測前です。

## 接続と電源

| 接続 | PCB側の割り当て | 条件 |
|---|---|---|
| J1 | 1: BAT_RAW、2: GND | Micro-Fit 3.0の極性を合わせた外部ヒューズ付き配線。2S候補。VBpower標準PHを大電流の出力経路として扱わない。 |
| J2 | 1: PH_A、2: PH_B、3: PH_C | 基板への直接はんだ付け用電線穴。0.25 mm²のフットプリントを選択。モーター線と相順の確定後に接続する。ワイヤは保持・絶縁する。 |
| J3 | 1: HALL_VCC、2: GND、3: A入力、4: B入力、5: C入力 | PCB側の順序。1525の5ピンへ直接差し込む仕様ではない。変換ハーネスで極性・相順・レベルを合わせる。 |
| J4 | 1: MCU_3V3、2: WHEEL、3: GND | 3.3 V対応の外部車輪センサー。ボード側10 kΩプルアップあり。 |
| TP1〜4 | DRVOFF、ILIM、AVDD、GND | 初回通電の測定点。 |

AP63205系の5 VをXIAOの5V端子へSchottky経由で供給。Schottkyはレギュレーターへの逆流を制限する。USBからモーター母線を給電しない。USB接続時はバッテリーを物理的に外す。初回電源はバッテリーとホットプラグを避け、電流・立ち上がり速度を制限した電源を使う。U1のVM立ち上がり絶対最大は4 V/µs。D1で母線過渡の抑制を意図するが、TVSの公称値をモーター端子の8.4 V制限とみなさない。[MCT8316Z Rev.B §7・§9・§11](https://www.ti.com/lit/ds/symlink/mct8316z.pdf)・[AP63205 データシート](https://www.diodes.com/datasheet/download/AP63200-AP63201-AP63203-AP63205.pdf)

Hall入力はU3でAVDDレベルに変換し、U1はデジタルHallモードで使用予定。HNxは開放。R12（AVDD）・R13（5 V）両方DNPで、モーター型番のセンサー給電条件を確定してから片方だけ取り付ける。R14〜R16もDNPで、出力形式を確認した際にのみ取り付ける。AVDDから給電する総負荷はU3/U5等の負荷を含めMCTの30 mA上限内とする。メーカーの端子配列・電圧・出力形式・位相対応は未取得。[MCT8316Z Rev.B §6・§8.3.2](https://www.ti.com/lit/ds/symlink/mct8316z.pdf)・[SN74LVC125A](https://www.ti.com/lit/ds/symlink/sn74lvc125a.pdf)

## MCU端子

| MCU | ネット | 機能 |
|---|---|---|
| D0 | VBAT_SENSE | 分圧240 kΩ/100 kΩ。VM 8.4 V時の公称2.47 V。ADC取得時間・校正と無給電時の注入電流を確認。 |
| D1 | WDI | 外部watchdog。制御ループ健全時に立下りを発行。 |
| D2 | MCU_PWM | U5経由で速度PWM。起動はLow。 |
| D3 | MCU_NCS | SPI選択。起動はHigh。 |
| D4 | ARM_EDGE | 出力禁止の解除には新しい立上りを要求。 |
| D5 | MCU_NFAULT | U6経由の故障読取。停止中のnFAULT状態もSPIと照合。 |
| D6 | WHEEL | 車輪パルス。 |
| D7 | HOST_RUN | 許可High。Lowおよびリセット時はラッチの非同期解除（禁止側）。 |
| D8 / D9 / D10 | MCU_SCK / MCU_MISO / MCU_MOSI | U5/U6を経由したMCTのSPI。 |
| 底面・内蔵用信号 | モジュール内 | 内蔵IMU/Flash接続を外部用途に割り当てない。 |

モジュール専用のパッド番号は003の既存ランドに合わせた番号です。D0=ランド14、D10=ランド4、5V=ランド1。MCU GPIO番号と同じ番号ではありません。[Seeed MG24 Sense端子表](https://wiki.seeedstudio.com/xiao_mg24_getting_started/)

## 禁止側の初期状態と通電順

1. R28（ARM LINK）をDNPにした状態で受領・実装検査する。U1 DRVOFFはAVDD側のR7でHighに保つ。BRAKEはLow固定。Q2は両方の電源が有効で、かつハードウェアラッチに許可が入った後にだけDRVOFFを引き下げる設計。R28未実装ではQ2をR29がOFFに保つ。
2. モーターとHallハーネスを外し、電流制限付き電源でAVDD、ロジック電源、DRVOFF、三相のHi-Zを確認する。DRVOFF Lowを駆動停止と取り違えない。USB・入力の片側給電、再投入を別々に確認する。
3. U7はTPS3431固定時間モード（SET1 High、CWDから10 kΩをVDD）。WDO/ENOUTはオープンドレインとして論理積を構成。U8が `WD_OK AND HOST_RUN` をラッチのnCLRへ出す。時計エッジのない通信復帰ではQは自動で許可にならない。タイムアウト時間、電圧復帰時、終了順は実測する。
4. 真のモーター端子表、相抵抗・相インダクタンスと入力上限を取得し、適合する変換ハーネスを作る。PWM=0の状態でSPI構成を書き込み、読戻しを照合する。MCTはモードにより111をアラインメントに使えるため、不正Hall状態での停止も確認する。
5. R5/R6 11.0 kΩ/10.0 kΩのILIM設定はAVDD=3.3 V、CSA=0.15 V/Aで約1.57 Aの計算点。パルスのブランキング、巻線インダクタンス、許容差、熱により実ピークは変わる。許可リンクを入れる前に回路側の禁止動作を確認し、リンク装着後の初回駆動も電流を制限して相電流を計測する。

回路図上の電流や遮断条件は設計値です。走行用の閾値・温度上限・停止時間を保証するものではありません。PCBの電力配線、RF近傍の銅箔、JLCPCBの部品受入・向き、シャーシ実寸は発注資料の確定時に確認します。
