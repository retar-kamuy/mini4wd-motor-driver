# 設計データと検証記録

| エンティティ | 必須項目と関係 | 検証条件 |
|---|---|---|
| 設計版 | `.kicad_pro`, `.kicad_sch`, `.kicad_pcb`, ライブラリ、ハッシュ | すべて正規パスの同一版。版変更後の検査結果は再生成 |
| 部品 | Reference、機能、メーカー、MPN、定格、資料URLと版、実装方法 | 候補と確認済みを区別し、実装品とBOM/CPLを一致させる |
| 端子対応 | 部品、回路図ピン、基板パッド、メーカー番号、ネット | 100%照合。重複パッドは全て確認。変更理由と根拠を記録 |
| 電流経路 | 動作モード、始点・終点、ネット、電流、層、幅/銅箔、ビア、狭窄 | 主経路と分岐を分け、5 A設計目標と銅厚・熱前提を評価 |
| 機構配置 | 基板外形、J1/J2位置・向き、部品外形、嵌合・禁止銅 | 反対端・外向き・資料の基板端条件と既存寸法を満たす |
| 検証結果 | 対象ハッシュ、手法、結果、根拠、残件、限界 | 古い版は履歴扱い。ヒューリスティックと測定結果を区別 |
| 製造パッケージ | 同一版のGerber、Excellon、BOM、CPL、検証記録 | 層・穴・部品・向きが同じ設計版に対応し、未確認条件を明記 |

状態は `未調査 → 候補 → 根拠確認 → 設計へ反映 → 同一版で検証`。未確定、誤検出、対象外は理由と根拠を添えて記録し、実装や試験の完了に置き換えない。
