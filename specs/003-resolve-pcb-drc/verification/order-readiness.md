# 基板製造・実装の発注条件

対象は `hardware/kicad/mini4wd-motor-driver/` の正規設計。個人利用で、発注枚数は必要に応じて決める。基板上の全SMT部品を業者に実装委託する。基板の裏面は電池に向け、部品を実装しない。

## 現在の正規版（2026-11-19）

38部品、BOM28行すべてメーカー/MPN/資料あり。正規PCB `a7aaab20cce23e1311411c16d31d7868e5d10233389f3a2941676cce5c175094` でERC/DRC/未接続/回路図パリティ0、全118パッド一致。55×21 mm、全品F.Cu、全82ビア裏面テント、電力0.8/0.4 mmビア33個。コネクタ本体の投影全長は約62.04 mmで、基板本体長とは異なる。

[同一版のGerber・BOM・CPL・IPCプレビュー](prototype-preview-20261119/) と [検査・解析・未実施の一覧](final-review.md) を保存済み。設計元20ファイルと成果物のハッシュを照合できる。これはPCBA業者の受入承認ではない。

昇圧の旧下限計算を訂正し、R1=75kΩ/R2=10kΩ・各0.1%/25ppmへ変更済み。静的/受動PDN・代表Gate/VDSモデルを再評価した。[結果と限界](preorder-electrical-20261118/README.md)。さらにR107入力放電抵抗を追加、R106を33Ω、C105を22µF/10Vへ変更し、L1/SWと局所GND帰路を改善した。[今回の正規検査・解析](return-path-20261119/README.md)。C105実効最小、全温度リーク最大/閉ループ起動、5Vでの全PVT入力閾値差と電圧低下中の論理は未保証。部分面で未解消のEMC帰路・5A熱目標も残す。実機測定は組立後に実施する。

[追加の主経路・熱予算](power-thermal-20261119/README.md)と[論理/MLCC判断](power-thermal-20261119/logic-capacitor-review.md)を保存した。PWMは公式core調査の1kHzを条件付き代表として用い、20kHzを一般許可しない。5A銅損と放熱条件を定量化したが、5A連続の無条件認定はしていない。主要5部品の端子・動作経路は再照合済み（T017完了）。

## 発注後に確認する事項

電流制限した初回通電、代表負荷での完成基板の電流波形・部品温度、実際の車体への搭載・配線確認は、完成基板が必要であり発注前には実施できない。これらの測定結果を試作発注前の条件とせず、発注前に試験方法と動作限界、未検証範囲を明記する。代表的なモーター条件で試作前の設計を評価し、未測定の全モーターの動作保証はしない。[搭載性の概略評価](chassis-clearance.md)は完了済みで、各シャーシの実測による適合保証は発注条件としない。

## 業者へ伝える未確認条件

- 全38品の業者実装。XIAO MG24 Sense 102010610はヘッダなしcastellated SMTモジュールとして供給/実装工程を確認し、利用者の手はんだへ転嫁しない。
- Q1ドレイン6個のパッド内ビアは穴埋め/キャップ、平坦性・吸い込み対策を確認。裏面テントを穴埋め済みと解釈しない。銅厚・最小めっき厚も指定する。
- 基板にfiducialはない。パネル枠/キャリアのfiducialと支持・工具穴、外向きコネクタの張り出し、端に近い部品を避けたデパネル方法を業者と照合する。
- 現CPLはKiCadの座標系（Y反転を含む）と回転。業者ライブラリで全品の向き・原点を確認する。
- 必要枚数、全品の調達在庫・支給可否、部品ロス・最低数、実装/送料を含む見積、業者DFM回答は未確認。外部への送信・発注はまだ行っていない。

電池・代表モーターの評価予算と試作後試験は [代表条件](prototype-design-release.md) を継続適用する。実効容量や未評価の解析条件は記録を残し、未実施測定を完了へ変更しない。
