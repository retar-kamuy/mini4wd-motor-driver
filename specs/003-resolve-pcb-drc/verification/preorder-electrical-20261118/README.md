# 発注前の電源・ゲート負荷の再評価（2026-11-18）

対象は正規 `hardware/kicad/mini4wd-motor-driver/`。変更前PCBは `514754f50fb7f77a5c9a6e01ddd9abdfa236c773fb83a3be6b39d33ad1f26724`。今回の設計判断は趣味用の代表条件での試作に対するもので、実物測定・全モーター/全温度の保証ではない。

## 修正する問題と採用判断

従来記録の「TPS61023基準0.600 V±2.5%、静的下限4.782 V、UVLO余裕132 mV」は誤り。[TI TPS61023 Rev.B p.5](https://www.ti.com/lit/ds/symlink/tps61023.pdf) のPWM基準580/595/610 mVを使うと、732k/100k・各1%の下限は4.741 V（約91 mV差）。抵抗の独立TCRまで積み上げると余裕がさらに減る。旧数値を現在の設計根拠として使わない。

R1を**75kΩ、R2を10kΩ、各0.1%/±25 ppm/K**へ変更する。選定はYageo **RT0603BRD0775KL / RT0603BRD0710KL**。[75kメーカー仕様](https://yageogroup.com/component-documentation/download/specsheet/RT0603BRD0775KL)、[10kメーカー仕様](https://www.yageogroup.com/component-documentation/download/specsheet/RT0603BRD0710KL) は0603/1608、1.6±0.1×0.8±0.1 mm、0.1 W/70°C、75 V。既存0603ランド、部品数37、配置・配線・全ネットを維持する。単に抵抗比だけ変える750k/100k・1%案は温度係数を含む動的感度で余裕不足が残るため採用しない。

TPS61023 §8.2.2.1はR2<300kΩを推奨し、低抵抗化はノイズ注入に有利と説明する。新比率の公称PWM出力は5.0575 V、分圧電流約59.5 µA、R1損失約0.266 mW。旧値より電流は約54 µA増えるがモーター負荷に対して小さい。

初期公差とTCRを独立最悪符号で−40～100°C（25°Cから最大75 K）へ積み上げ、FBリーク±20 nA感度を加えた静的包絡は**4.9036～5.2129 V**。UCC27524ADR/SOICのUVLO起動最大4.65 Vとの差は約254 mV。**20 nA最大は25°Cのみ。125°Cは典型値しかなく、全温度リーク最大を保証した計算ではない。** 抵抗温度範囲は感度条件であり、X5R等を含むシステム全体の100°C動作許可でもない。

## 接続先上限と入力条件

生XMLでBOOST_5V接続はU2/6、U104/6、C2/C3/C104/C105、R1、D2アノード、XIAO_5VはD2カソードとMCU1/1であることを照合した。

| 接続先 | 設計の照合と限界 |
|---|---|
| TPS61023 VOUT | 推奨設定上限5.5 V。上の5.2129 Vは下回る。OVPは典型5.7 Vであり、5.5 V以下へクランプする保護ではない |
| UCC27524ADR VDD | [TI UCC27524A](https://www.ti.com/lit/ds/symlink/ucc27524a.pdf) 推奨4.5～18 V。起動側はDパッケージ4.65 V最大を使用 |
| C2/C3/C104/C105 | それぞれ10/10/10/16 V候補。耐圧余裕と実効容量は別である |
| Q1/Q2ゲート | Q2 DMP2008UFGのVGS定格±8 Vに対し、VBAT=0の静的正VGS上限5.213 V。オーバーシュートや負のリンギングを含む保証ではない。Q1も静的5.213 Vで既存定格内 |
| XIAO 5V端子 | [Seeed公式回路図 pp.4–5](https://files.seeedstudio.com/wiki/XIAO_MG24/Getting_Start/XIAO_MG24_SCH.pdf) をPDF取得・目視確認。5V端子はモジュール内D1後段のVINであり、USB VBUSとは別。VINの[TPS628438推奨入力上限5.5 V](https://www.ti.com/lit/ds/symlink/tps62843.pdf) に対し静的約287 mVの差。外部D2の最低Vfを仮定せず、端子最大≤BOOST最大として評価。モジュール全体の供給許容範囲のメーカー保証や実過渡の測定を得た意味ではない |

XIAO内D1がVIN→USB VBUSを遮ることを図面で確認し、本基板D2はUSBからBOOSTへの逆流を遮る。XIAOのLiPo端子は本設計では使用しない。SGM40567充電器やSGM2040はVBUS側にあり、外部5V端子直結と誤認しない。

電池はNiMH/アルカリ単3×2。試作解析の代表入力は**1.8/2.4/3.0/3.4 V**。3.4 Vは新電池側を含めた設計評価上限という仮定で、あらゆる電池型番の開放電圧・接点バウンス・回生ピークを保証する値ではない。TPS61023の起動入力最低1.8 Vと区別し、1.8 V未満の起動を要求しない。電池降下中の再起動・MOSFET切替は組立後の電流制限付き試験で確認する。

## 実行したPDN感度解析

[evaluate_pdn.py](evaluate_pdn.py) をngspice 45.2で実行。[JSON](pdn-results.json) / [CSV](pdn-results.csv) / `pdn/` の96デッキとログを保存。これは**受動充電配送の感度モデル**であり、TPS61023制御ループ/起動モデルの合格ではない。事前に最小電圧へ充電後、供給を15 µsで切り、25 µs間はコンバータの応答を一切与えない。DC負荷の影響はこのモデルに含まない。

- C2+C3実効合計4/10 µF、C105実効0.5/1 µF、C104実効60 nF。
- 配線0.05/0.25Ω、10/100 nH、local ESR20 mΩ/ESL1 nH、bulk ESR10 mΩ。
- 代表電荷Q1/Q2=80/100 nC、電流ピーク0.8/0.2 A。過大側予算300/300 nC、ピーク1/0.25 A。三角波の幅を電荷から導く。Q1メーカー表はVGS4.5 Vで最大32 nC、10 Vで最大68 nC、Q2は−2.5 Vで40 nC、−4.5 Vで72 nCの典型値。試験電圧/電流が異なり、この予算をQ2全個体最大保証とは扱わない。抵抗R105/R106を無視した6 Aの非現実的な短パルスは最終解析に使っていない。

| 分圧案 | 代表電荷16条件中の最小 | 300/300 nC予算の最小 | 判断 |
|---|---:|---:|---|
| 732k/100k、1%/100 ppm | 4.540 V | 4.332 V | 低電圧/温度感度の改善が必要 |
| 750k/100k、1%/100 ppm | 4.640 V | 4.432 V | 比率変更だけでは不足 |
| 75k/10k、0.1%/25 ppm | **4.779 V** | 4.571 V | 代表全16条件は4.65 V以上。過大電荷予算はC105実効0.5 µFの4条件で4.65 V未満 |

新案でC105実効1 µFなら、300/300 nC予算の全8条件が**4.698 V以上**。C105実効1 µFは採用品の全温度/バイアス/経年に対する保証値ではなく、設計感度の条件。公称2.2 µFだけを根拠に達成済みとはしない。4.65 Vは起動UVLO最大を運転中にも比較した保守的指標で、実際のヒステリシス動作や遮断時間のモデルではない。
