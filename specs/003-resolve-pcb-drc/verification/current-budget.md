# 主電流経路と5A目標の評価

## 2026-11-19：端子と動作経路の照合、定量評価

正規a7aaab20…5094の[主要5部品のパッド監査](power-thermal-20261119/power-pin-audit.json)と全118パッド/XML一致に基づく。Q1はメーカー1–3=S/4=G/5–8=DをPCB共通drainランド5で受け、S=GND/G=Q1_GATE/D=MOTOR_MINUS。Q2は1–3=S=VBAT/4=G=Q2_GATE/5–8=D=MOTOR_MINUS。Molex端子1正極とメーカー形状は既存機械照合を維持する。Comchip SS54-HFの帯側CathodeはD1/1=VBAT、AnodeはD1/2=MOTOR_MINUSである。従来の「D1資料未取得」という状態を、この版へ適用しない。

| 状態 | 銅経路と役割 |
|---|---|
| 駆動 | J1/1→J2/1→モーター→J2/2→Q1 D/S→J1/2。Q1 ON/Q2 OFF |
| 短絡ブレーキ | J2/1–VBAT–Q2 S/D–MOTOR_MINUS–J2/2でモーター両端を閉じる。Q1 OFF/Q2 ON。蓄積電流/発電制動で電流方向が変わり得るためQ2チャネルを双方向として扱う |
| 切替の両MOSFET OFF期間 | 正方向の巻線電流はMOTOR_MINUS→D1 A/K→VBATへ還流。Q2 body diodeとの分担は実波形依存 |
| 検出 | R5/MID_SENSEへ向かう細線は検出枝であり5A主経路ではない |

主経路の1D抵抗網、製造仮定、狭窄・ビア分担の限界、接点/部品損失と216/324条件の熱感度を[追加評価](power-thermal-20261119/README.md)へ保存した。35µm/20°Cの駆動銅30.626mΩ/5A0.766W、ブレーキ銅18.711mΩ/0.468W。5Aの熱成立は放熱・実銅厚・接触等に依存し、無条件の連続定格とはしない。代表PWMは[core調査](pwm-core-research.md)の1kHzを条件付きで使い、20kHzはD1熱の認定値ではない。以下は旧版の調査履歴。


**2026-11-19の現版:** 38部品版でも33個の電力ビア・J1/J2端子・既存主電力バスを保全した。追加R107は3.3V HIGH時約1.53mAの小電流枝。5A連続の熱認定は未達。 [検査・根拠・未保証事項](return-path-20261119/README.md)。以下の旧版数値/部品は履歴として扱う。

2026-11-17追記: 正規37品版の実際の主幹幅・3/6並列ビアとめっき仮定は [電力ビア差分評価](pcba-bom-stage/power-via-review.md)、形状・端子対応は [最終照合](pcba-bom-stage/final-connectivity.json)。5 A連続実測は未実施。以下の過去版・設計予算を混同しない。

基準設計は [design-baseline.md](design-baseline.md)。pcbnew によるネット・パッド列挙の結果、J1-1 と J2-1 は VBAT、J1-2 は GND、J2-2 は MOTOR_MINUS。Q1 1–3 は GND、Q1 5 は MOTOR_MINUS。基準版では Q2 5番が誤って VBAT だった。Q2修正時の版では 1–3=VBAT、4=GATE_DRIVE、5–8および重複Drain=MOTOR_MINUS に修正した。分離ゲート回路を統合した2026-11-14版はQ1 gate=GATE_N、Q2 gate=GATE_P。結果と版は [q2-repair.md](q2-repair.md) を参照。

意図した駆動は J1+ → VBAT → J2-1 → モータ → J2-2 → Q1 D/S → J1−。短絡ブレーキはモータの両端を Q2 を通じてつなぐ。D_FLY は MOTOR_MINUS から VBAT への還流経路。実際の動作、切替時の同時導通、各部品の損失は未検証。

基準PCB上の全セグメントをネット別に数えると、VBAT は 1.0、1.2、1.5 mm 等、MOTOR_MINUS は 0.3、0.4、0.6、0.8、1.0 mm、GND は 0.3、0.35、0.4 mm がある。これらの中には信号分岐が含まれるため、各数値が主電流の最小幅だとは断定しない。VBAT のビアはドリル 0.3 mm × 8、MOTOR_MINUS は同 × 4、GND は同 × 15。並列に電流を分担する配置かどうかは別途トポロジー解析が必要であり、単純な合計を主経路のビア数として使わない。

1 oz 銅厚は現時点の設計仮定で、製造後の最小銅厚、ビアめっき厚、波形、周囲温度、許容温度上昇は未確定。5 A 連続目標を満たすと判定できない。機能、重なり通電、ピーク・還流損失、銅箔およびビアの局所電流を再設計後に評価する。

## 利用者が指定した電池条件

NiMHとアルカリの両方を使用する。前回の選択肢の文脈に従って単3形2本を対象とする。利用者は、ミニ四駆に搭載可能なモーターを型番で限定せず利用できることを要求している。セル型番・使用温度・放電終止電圧・ストール電流の代表値は未確定だが、特定モーターの指定を待つのではなく、対象範囲と電池の組合せを資料に基づいて調査する。5 A連続目標は起動・ストール時の上限を意味しない。起動の低電圧側はTPS61023の起動最低1.8 Vも考慮する。動作継続の最低入力0.5 Vを起動可能電圧と取り違えない。

現行版のVBAT/GND/MOTOR_MINUSセグメント・ビアのUUID、座標、層、幅と穴径を [power-routing-inventory.csv](power-routing-inventory.csv) に抽出した。これは主経路の許容電流判定ではなく、再設計と差分照合に使う基準記録である。

## 2026-11-14 主経路の局所形状と理想DC試算

PCB SHA-256 `7cc2d8694f2d7c50decf81c6e64b0065434d00a87d77c2727acef66c479f77fa` をpcbnewで再読込し、0.8 mm径・0.4 mmドリルのビアの位置を照合した。J1のVBAT側は `(5.55,9.0)`・`(6.5,9.0)`・`(7.4,9.0)`、GND側は `(5.55,12.0)`・`(6.5,12.0)`・`(7.4,12.0)` mm。J2のVBAT側は `(48.5,12.0)`・`(49.45,12.0)`・`(50.35,12.0)`、MOTOR_MINUS側は `(48.55,9.0)`・`(49.45,9.0)`・`(50.35,9.0)` mm。Q1のGND側には `(46.5,17.3)`・`(46.5,18.2)`・`(46.5,19.1)` mm、MOTOR_MINUS側には `(50.2,17.7)`・`(51.1,17.7)`・`(50.2,18.6)`・`(51.1,18.6)` mmのビアがある。Q2付近にもVBATとMOTOR_MINUSそれぞれ3個を配置している。

これは同一ネットの位置確認であり、各ビアへの接続抵抗や電流分担を確認したものではない。J1/J2端子やQ1の端子付近はランドおよび0.6～1.2 mmの短い枝で接続され、局所的な電流集中が残る。[全区間の一覧](layout-power-routing.csv)と合わせて確認する。

感度確認として、銅抵抗率1.724×10⁻⁸ Ωm（20°C）、完成銅厚35 µmを仮定した理想的な直線銅箔のDC抵抗と、全5 Aが各1本の線に流れる場合の損失を計算した。2.0 mm幅は0.246 mΩ/mm・6.16 mW/mm、1.5 mm幅は0.328 mΩ/mm・8.21 mW/mm、0.6 mm幅は0.821 mΩ/mm・20.5 mW/mm。0.6 mmの枝すべてに5 Aが流れると仮定した比較値であり、実際の分担や温度上昇ではない。

ビアの参考計算では、ドリル径0.4 mmの穴にめっき25 µmを内側へ施した理想円筒、長さ1.6 mm、同じ銅抵抗率を仮定すると、1個約0.937 mΩ。3個が完全に均等分担する理想条件では合成約0.312 mΩ、5 A時の合計ジュール損失は約7.8 mWとなる。完成穴径・めっき厚・電流分担は未確認であり、この値を実基板の保証値として使わない。計算条件と数値は [power-worksheet.json](power-worksheet.json)。

端子抵抗、はんだ接合、温度による抵抗増加、電流集中、材料公差、PWM・ストール波形および実効電流を含む評価は未実施。これらを解決するまでT018は未完了であり、5 A連続の適合を判定しない。

## 端子と動作モードの照合状況

現行の[q2-readable-netlist.xml](q2-readable-netlist.xml)では、J1-1/J2-1/Q2-1～3/D1-1がVBAT、J1-2/Q1-1～3がGND、J2-2/Q1-5/Q2-5～8/D1-2がMOTOR_MINUS。D1の回路図シンボルは1=K、2=Aである。PCBの同じ端子ネットもpcbnewで照合した。回路図上の順方向はMOTOR_MINUSからVBATであり、モータ電流と過渡波形によって還流時に導通し得る。実際のクランプ電圧やD1の許容パルス損失を示すものではない。

Q1候補 [Vishay SiSS64DN資料 p.1](https://www.vishay.com/docs/67294/siss64dn.pdf) は1～3=S、4=G、5～8=D。正規PCBは1～3=GND、4=GATE_N、5=MOTOR_MINUSで、基板上の番号5の大きいDrainランドが物理部品の複数Drain端子を受ける前提となっている。Q1の回路図ライブラリ名は `SiS454DN` であり、候補部品そのもののシンボルではない。端子名の一致だけでなく実際のランドが5～8すべてを覆うこと、はんだマスクとビアを含むメーカー寸法照合が必要。Q2は1～3=S、4=G、5～8=Dで、対応と図面表示の確認は [q2-repair.md](q2-repair.md) を参照。

駆動状態の想定経路はJ1-1 → J2-1 → モーター → J2-2 → Q1 → J1-2。ブレーキ状態はモーターのJ2-1側からVBAT → Q2 → MOTOR_MINUS → J2-2側へ閉じる。これは接続から導いた経路であり、MOSFETの切替、同時導通防止、逆起電力、コネクタやD1の定格の合格を意味しない。D1候補の製造元資料URLは今回アクセス時に製品一覧へ転送されたため、物理端子図・定格を今回再確認できていない。J1/J2のメーカー図面との端子・嵌合照合も残っており、T017は未完了とする。

## 型番を限定しない要件と既存5 A目標

メーカー資料には推奨負荷時に最大5.2 Aと記載された搭載可能モーターがあるため、既存の5 A連続目標だけで利用者の要件を評価することはできない。この数値はストール上限でも全対象の最大値でもない。根拠と未確定条件は [motor-load-envelope.md](motor-load-envelope.md)。T038/T039で負荷包絡と設計を検証し、T018の電流・熱評価へ反映する。
