# 主電流経路の調査（未完了）

基準設計は [design-baseline.md](design-baseline.md)。pcbnew によるネット・パッド列挙の結果、J1-1 と J2-1 は VBAT、J1-2 は GND、J2-2 は MOTOR_MINUS。Q1 1–3 は GND、Q1 5 は MOTOR_MINUS。Q2 は 1–3 VBAT、4 GATE_DRIVE、5 VBAT、6–8 MOTOR_MINUS。Q2 5番の誤接続は [parts-evidence.md](parts-evidence.md) に記載した重大な短絡原因で、経路評価より先に修正する。

意図した駆動は J1+ → VBAT → J2-1 → モータ → J2-2 → Q1 D/S → J1−。短絡ブレーキはモータの両端を Q2 を通じてつなぐ。D_FLY は MOTOR_MINUS から VBAT への還流経路。ただし実回路のQ2 5番誤接続を含む現状では意図通りの動作を保証できない。

基準PCB上の全セグメントをネット別に数えると、VBAT は 1.0、1.2、1.5 mm 等、MOTOR_MINUS は 0.3、0.4、0.6、0.8、1.0 mm、GND は 0.3、0.35、0.4 mm がある。これらの中には信号分岐が含まれるため、各数値が主電流の最小幅だとは断定しない。VBAT のビアはドリル 0.3 mm × 8、MOTOR_MINUS は同 × 4、GND は同 × 15。並列に電流を分担する配置かどうかは別途トポロジー解析が必要であり、単純な合計を主経路のビア数として使わない。

1 oz 銅厚は現時点の設計仮定で、製造後の最小銅厚、ビアめっき厚、波形、周囲温度、許容温度上昇は未確定。5 A 連続目標を満たすと判定できない。機能、重なり通電、ピーク・還流損失、銅箔およびビアの局所電流を再設計後に評価する。
