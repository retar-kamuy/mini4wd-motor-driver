# 電源帰路・入力消失・ゲート抵抗の追加評価（2026-11-19）

対象は正規 `hardware/kicad/mini4wd-motor-driver/`。開始時PCB SHA-256は `e7152f915355a188716b45264bc74a34fdb6dc9e5e9074a5caea470124906ac7`。本記録のモデル感度とメーカー保証値を区別する。実物の波形・温度・EMCを測定した記録ではない。正規反映と最終CAD検査の結果は末尾に記す。

## 判断の根拠

1. 従来のMCU喪失モデルはENAを先にLOWとしていた。実際のTLV809Eには電圧低下からリセットまで最大50µsの伝搬遅延があり、この前提だけでは入力の蓄積電荷によるQ1の残留駆動を評価できない。
2. `N_COMMAND` に外付け **R107=2.2kΩ、1%、0402、Vishay CRCW04022K20FKED** の放電経路を設ける。LVC電源喪失時の典型UCCモデル内部400kΩだけへの依存を減らす。未給電時に実物LVCがどの速度で高インピーダンスへ移行するかは未保証である。
3. Q2ゲート抵抗 **R106を22Ωから33Ω、1%、CRCW040233R0FKED** へ変更し、5V喪失時の追加Q1容量感度での閾値重なりを減らす。Q1側R105=4.7Ωは維持する。
4. U104直近の **C105を2.2µF/16Vから22µF/10V、Murata GRM188R61A226ME15D** へ増量する。C2/C3と同じ0603品を共用し、フットプリント面積を増やさない。公称値を実効最小値とみなさない。
5. L1を同じ中心で180°回転し、SW側をU2へ向ける。SWはF.Cu内だけの短い経路とし、昇圧・ドライバ側へGND面と接続ビアを加える。XIAOの下には新規GND面を広げない。

## 保証値と入力レベル

[SN74LVC1G08 Rev.AA §5.5](https://www.ti.com/lit/ds/symlink/sn74lvc1g08.pdf) はVCC=3.0V、IOH=−16mAでVOH≥2.4V（−40～125°C）。[UCC27524A Rev.C §5.5](https://www.ti.com/lit/ds/symlink/ucc27524a.pdf) のSOIC/D入力HIGH閾値最大は2.3V、温度条件−40～150°C、表の既定電源条件はVDD=12Vである。温度範囲はXIAOの−20～70°Cを包含するが、**2.4−2.3=0.1Vをそのまま本基板の5V全PVT保証余裕とはしない**。UCC本文は入力閾値をVDD非依存と説明するものの、5Vでの最大閾値を独立条件として表記していない。GND差・雑音・電源低下中の動作もこの差に含まれない。

R107の最悪初期抵抗2178Ωと3.333Vで、追加HIGH負荷は約1.53mA、抵抗電力約5.10mW。UCC入力負荷を加えてもLVCの16mA試験負荷より十分小さいという設計判断であり、出力特性の全条件補間を保証するものではない。LVCのIoff最大10µAがこの経路だけに流れる感度なら約22mV。UCCの内部プルダウンは典型マクロ値を使った感度に限る。

XIAO公式回路図のTPS628438に対し、[TI Rev.C §6.5](https://www.ti.com/lit/ds/symlink/tps62843.pdf) のPWM DC精度は−20～125°Cで±1%、従って公称3.3Vの静的範囲は3.267～3.333V。−40～125°Cでは±1.5%。これはPWM精度であり、PFMリップル、外部負荷過渡、配線降下、起動/切断中の下限を保証しない。VCC≥3.0Vの定常区間では上記LVC条件を保守的に参照する。3.0V未満へ落ちてからTLV809Eが応答する区間の論理HIGH余裕は保証未成立である。

## C105実効容量、安定性、突入

[TI TPS61023 Rev.B §6.3/8.2.2.4](https://www.ti.com/lit/ds/symlink/tps61023.pdf) の推奨は入力実効≥1µF、出力実効4～1000µF、L=0.37～2.9µH。出力実効40µF超ではフィードフォワードコンデンサを推奨する。公称3×22µFという合計だけでこの実効閾値を判定しない。

GRM188R61A226ME15Dは公称22µF±20%、X5R、10V、0603。[TIのメーカー技術者によるMurata SimSurfing参照回答](https://e2e.ti.com/support/power-management-group/power-management/f/power-management-forum/1258565/tps61022-output-voltage-drops-below-input-voltage) では5V時に約5.5µFとされる。これは典型の参照情報であり、当該品の全ロット/5.213V/温度/経年のメーカー最小保証ではない。例えば5.5µFへ初期0.8、温度0.85、経年0.9を掛ける計画感度は3.37µFとなるが、これも保証式ではない。実効容量の測定または正式な特性照合を試作後の最初の確認項目に残す。

[cap-pdn-results.json](cap-pdn-results.json) の96受動PDN感度は全完走。初期電圧4.90355V、各ゲート電荷300nC、DC負荷20/50mA、コンバータ無応答5/25µs、bulk実効4/10µF、局所実効1/2/4µF、配線0.05/0.25Ω・10/100nHを与えた。最も厳しい50mA/25µsの最小電圧は局所1/2/4µFで **4.527/4.588/4.664V**。4µF感度では全条件が起動UVLO最大4.65V以上だが、**採用品が4µFを保証する証明にはならない**。既存2.2µFを増量する方向の根拠とし、供給過渡合格としない。

[startup-cap-budget.json](startup-cap-budget.json) は50/110µF、出力で利用可能50/100/200mA、起動負荷0/20/50mAを仮定した定電流予算。110µF、5.213Vのエネルギーは約1.495mJ、利用可能50mA−負荷20mAなら約19.1ms、100mA−20mAなら約7.17ms。電流余裕が0以下ならこのモデルでは起動できない。TPSの保証起動電流・制御ループのシミュレーションではない。TLV809Eの最小130ms遅延は3V3立上り後から数えるため、BOOSTが先に安定することを無条件に保証しない。追加容量の実効合計、突入、TPS安定性とUVLO反復は実機確認へ残す。
