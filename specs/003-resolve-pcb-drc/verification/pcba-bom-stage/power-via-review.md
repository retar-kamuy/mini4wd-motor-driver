# 電力ビアと主経路の差分評価（2026-11-16）

## 判定と限界

電力用の0.8/0.4 mmビアは、2026-11-14の35部品検証版25個に対して最終37部品版33個。比較対象の版を区別する。途中候補で新設部を0.6/0.3 mmとしたが、5 Aに対する径縮小の根拠が不足したため採用を撤回し、0.8/0.4 mmへ統一した。DRC0だけを根拠に電流容量が同等と判定しない。

以下はRaw-file verifiedの穴径・本数・表裏のバス接続と、仮定に基づく抵抗計算である。並列の実電流分担、5 A連続時の基板/FET温度上昇、めっきの完成厚は未測定。**連続5 Aの実証済み保証ではない**。試作発注前は設計/解析の根拠を固定し、実負荷評価は試作後の受入検証に残す。

## 5 Aを使う設計上の抵抗見積り

めっき完成厚20µm、板厚1.6mm、銅の抵抗率0.01724 Ω·mm²/m、完成穴径0.4mmを仮定する。バレルの近似断面積πdt=0.02513mm²、単体抵抗は約1.10mΩ。理想均等3並列なら合成約0.366mΩで、合計5 A時の損失は約9.15mW/ノード。6並列なら約4.58mW/ノード。

これはめっき厚を測定した値でも、熱モデルによる温度保証でもない。実際の分担はF.Cu/B.Cuの長さ・幅、パッドとバレルの接触抵抗、温度で偏る。仕上げ穴径/最小めっき厚と穴埋め/キャップは業者の製造条件へ指定し、試作で電流・温度を確認する。径・並列本数を旧版より減らしたことによる根拠のない後退は解消したが、5 A連続実測完了とは扱わない。

## 試作を待たず指定する製造条件

- Q1ドレインの6個はパッド内ビア。穴埋め・銅キャップ等、はんだ吸い込みを抑える工程と仕上がり平坦性をPCBA業者へ指定/確認する。裏面テントだけでは完了としない。
- その他ビアも完成穴径、めっき最小厚、F.Mask/B.Maskを提出データと照合する。全75個はB.Cu側テント指定。
- 0.6/0.3 mmの42個はゲート/ロジック/検出等の配線で、環幅0.15mm。0.5/0.3 mmビアは残さない。
- 駆動経路はVBAT J1→J2、MOTOR_MINUS J2→Q1、GND Q1→J1。ブレーキ/還流経路はJ2→Q2/D1→VBAT。R5へ向かう0.15mm MOTOR_MINUSは検出枝であり、負荷電流の通り道ではない。
