# モーター負荷範囲の調査（未完了）

利用者は「ミニ四駆に搭載可能なモーターであれば利用可能」を要求しており、単一型番による範囲限定はしない。単3形NiMH・アルカリ各2本を対象とする。公認レースで使用できるモーターだけに限定する指示は受けていない。

[タミヤのプラズマダッシュモーター製品ページ](https://www.tamiya.com/japan/products/15186/index.html)は、ミニ四駆各車に使用可能とし、適正電圧2.4～3.0 V、推奨負荷トルク時の消費電流4.1～5.2 Aを掲載している。公認レースには使用できないという注記もあるが、利用者の要件から除外する根拠にはならない。同ページは掲載情報が2019年7月1日時点で、仕様が変更され得るとしている。

従って、既存の **5 A連続という設計目標だけでは、この例の推奨負荷時の掲載値の上端まで対象にした根拠にならない**。5.2 Aを全モーターの最大値や新たな設計上限とみなすこともできない。掲載値は推奨負荷トルク時の消費電流であり、起動・停止・ストール・短絡ブレーキ時のピーク値や継続時間ではない。

[タミヤのモーターガイド](https://www.tamiya.com/cms/english/mini4wd/setupguide/motorguide.pdf)には単軸とPRO用両軸を含む複数のモーターが示される。これは候補の洗い出しの入口であり、過去・現行・他メーカー・改造品を含めたすべての搭載可能モーターを網羅する証明ではない。型番を選別して要求を狭めず、機械的な搭載範囲と電気的な負荷包絡を整理する。

未解決: モーター巻線抵抗と温度・個体差、最大入力電圧、電池の内部抵抗と供給能力、起動／ストール／ブレーキのピークと持続時間、電池電圧低下時の制御動作。資料で上限を確定できない部分は、対応する測定・保護・設計上の境界と、その範囲外の動作を明示して検証する。安全な回路の実現可能性は未評価であり、単一の電流閾値や保証範囲をここで仮定しない。T038/T039は未完了。
