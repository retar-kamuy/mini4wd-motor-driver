# 論理余裕と実効容量の追加判断

2026-11-19、正規a7aaab20…5094の評価。新しいCAD変更は行わない。一次資料の保証条件と、机上モデルの条件を合わせて判断する。

## 論理入力

[SN74LVC1G08 Rev.AA §5.5](https://www.ti.com/lit/ds/symlink/sn74lvc1g08.pdf) はVCC3.0V/IOH−16mAでVOH≥2.4V、−40～125°C。[UCC27524A Rev.C §5.5](https://www.ti.com/lit/ds/symlink/ucc27524a.pdf) のSOICは入力HIGH最大2.3V、LOW最小1.0V、既定VDD12V/−40～150°C。R107追加HIGH負荷約1.53mAは16mA試験負荷より小さいが、100mVを雑音や全電源過渡を含む保証余裕とはしない。LOWは同LVCのVOL最大0.4V/16mAと比べて0.6V差がある。

UCCの製品説明はVDDに依存しないTTL互換入力とする一方、典型図5-8は5V付近の上り閾値が約1.6V、12V付近で約2Vという変化も示す。5Vの典型値は十分低い方向だが、別の最大保証値をこの図から作らない。温度範囲はXIAOの−20～70°Cと整合する。XIAO内TPS628438のPWM静的±1%から3.267～3.333Vと計算できるが、PFM/立上り/低下/リップルは別である。

N_COMMANDが50pFを保ち、R107最大2222Ω、LVC未給電リーク10µAが流れる感度なら、最終電圧約22.2mV、時定数111ns。3.333Vから1.0Vまで約136nsというRC計算になる。50pFは全寄生の保証最大ではない。既存の[6条件の電荷保持SPICE](../return-path-20261119/input-retention-results.json)と合わせ、R107を設ける設計根拠とする。UCCマクロ内部400kΩは実品の最小保証ではなく、公表典型曲線の約180kΩとも異なる。2.2kΩを外付けすると内部120～400kΩの違いによる合成時定数変化は約2%以内という感度になり、内部抵抗だけに依存する設計から改善する。

今回、5Vの全PVT入力閾値、監視器の最大50µs応答期間、LVCの不定電圧領域を完全保証する新資料は得ていない。通常の電源降下では5VドライバUVLOとXIAO内部降圧の順序を評価する必要があり、3V3だけが独立に失われる故障モデルをすべての通常切断と混同しない。既存の瞬時喪失・電荷保持感度も任意の緩い/速い全電圧傾斜の認定ではない。

## C105とUCCの比較基準

UCC27524A/SOICは、起動VON最大4.65V、起動後VOFF最大4.4V、推奨動作下限4.5Vを区別する。従来PDN感度で4.65Vを割ることを、そのまま運転中のUVLO再起動と判定しない。

既に完走した[PDN96条件](../return-path-20261119/cap-pdn-results.json)は、C105実効1/2/4µFの各32条件で最小 **4.527/4.588/4.664V**。実効2µFなら推奨4.5Vに約88mV、停止側4.4Vに約188mVの感度余裕がある。起動時4.65V到達や実物の制御応答/実効容量の証明とは別である。

同じ定電流・定容量の線形受動モデルに限り、初期電圧を4.90355Vから静的上側5.21289Vへ移す重ね合わせ計算では、実効1/2/4µFのピーク推定は **5.466/5.394/5.321V**。2µF感度は5.5Vへ約106mVの差を残す。これは新たなTPS閉ループ/SPICEの完走結果ではなく、既存受動モデルのオフセット計算である。全温度リーク上限、電圧依存C、コンバータ/USBの応答を含む保証に転用しない。

## 当該MLCCのメーカーReference Sheet

メーカーが作成した [GRM188R61A226ME15-02A Reference Sheet（LCSC公開ミラー）](https://datasheet.lcsc.com/datasheet/pdf/8c937b24e7d196f654803406b908d797.pdf?productCode=C2840479) は、当該系列の22µF±20%、10V、0603、X5R±15%/−55～85°C、D=4000個/reelを記載する。本文の容量測定は室温120±24Hz/0.5±0.1Vrms、温度特性は**無バイアス**。従って温度±15%と初期公差だけを掛けても5.213Vでの最小容量にはならない。この資料は2017年のReference Sheetであり、現時点の供給や最新承認仕様は別途確認する。

公式SimSurfingは当該品のDC-bias項目を提供するが、この環境では動的CSV/曲線の数値を取得できず、公開ページの直接取得もHTTP403となった。サイト閲覧できたことを曲線確認済みへ読み替えない。[TI技術者のSimSurfing参照回答](https://e2e.ti.com/support/power-management-group/power-management/f/power-management-forum/1258565/tps61022-output-voltage-drops-below-input-voltage)による5V時約5.5µFは典型の補助根拠に留める。

現採用22µFは従来2.2µFから容量余裕を増し、実効1/2/4µFの感度を覆う方向の選定である。全ロット/バイアス/温度/経年の最小保証は未取得。2µFを計画条件とすれば定常の推奨VDD4.5Vを96条件の対応部分で下回らないが、これをメーカー保証とは呼ばない。[TPS61023 §8.2.2.4](https://www.ti.com/lit/ds/symlink/tps61023.pdf) の実効出力4～1000µF、40µF超のfeedforward推奨も、実効容量の条件で判断する。C2/C3/C105の典型合計約16.5µFは40µFより小さいが、閉ループ安定性/突入/起動を完了した意味ではない。

試作後の最初の通電でBOOST/U104 VDDとXIAO3V3を観測し、過渡・UVLO・不意な駆動を確認する。実機測定を試作発注前に要求せず、机上で確認できた条件と未保証を残す。上記の資料不足だけを理由に根拠のない部品追加や、未検証の補償コンデンサを追加しない。
