# 5A主経路・PWM還流の定量予算（2026-11-19）

正規PCB **a7aaab20cce23e1311411c16d31d7868e5d10233389f3a2941676cce5c175094** を読み取った追加評価。CAD変更は行っていない。[同版CAD検査/製造出力](../return-path-20261119/README.md)を継続適用する。計算の仮定・境界条件を明示し、実基板の温度や5A連続保証へ読み替えない。

## 主経路の抵抗と損失

[evaluate_power_paths.py](evaluate_power_paths.py) は実配線の幅・端点・交差、パッド接続、ビア径/穴を読み、1D中心線の抵抗網を解いた。直列/並列の既知回路とKCL・電力収支の数値チェックを実施。[結果](power-path-results.json)。銅抵抗率0.01724Ω·mm²/m（20°C）、完成銅厚35µm、ビアめっき20µm、板厚1.6mmは製造前の仮定。

| 5Aを流す銅経路 | 抵抗・20°C | 銅損失 |
|---|---:|---:|
| 駆動：J1+→J2+ | 12.827mΩ | 0.321W |
| 駆動：J2−→Q1 drain | 3.772mΩ | 0.094W |
| 駆動：Q1 source→J1− | 14.027mΩ | 0.351W |
| 駆動合計 | **30.626mΩ** | **0.766W** |
| ブレーキ：J2+→Q2 source | 9.820mΩ | 0.246W |
| ブレーキ：Q2 drain→J2− | 8.891mΩ | 0.222W |
| ブレーキ銅合計 | **18.711mΩ** | **0.468W** |

70µm銅厚・同じビアめっきの感度では駆動合計16.291mΩ、5Aで0.407W。**70µmは選択済み製造仕様ではない。** 現配線には0.127mm幅/クリアランスがあり、単純に2ozへ変えて業者DFM適合としない。

パッド/同一MOSFET端子は理想等電位、ゾーン・はんだ・接触・配線の面内拡がりをモデルに含めない。特に幅広配線の端部同士の面接触は中心線だけでは表現できず、D1分岐付近などのビア電流は実分担と異なり得る。JSONの分担値はこの近似網の値であり、実ビア電流の証明や均等分担の根拠に使わない。正確な分布には2D/3D銅メッシュが必要。温度係数、完成銅厚、はんだ/端子損失は別に評価する。

## 部品と外部配線の根拠

- [Vishay SiSS64DN Rev.B](https://www.vishay.com/docs/67294/siss64dn.pdf): VGS4.5VのRDS最大2.86mΩは25°C/パルス条件。5A導通損0.0715W、高温2倍感度0.143W。公表RθJA定常63°C/Wはメーカー試験基板条件で、本PCBの値ではない。
- [Diodes DMP2008UFG Rev.14-2](https://www.diodes.com/datasheet/download/DMP2008UFG.pdf): VGS−1.5VのRDS最大17mΩは25°Cのパルス試験。5A導通0.425W、高温2倍感度0.850W。資料に52/137°C/Wがあるが、本PCBの熱抵抗ではない。5A一定ブレーキでTj125°C/周囲40°Cを狙うなら、この0.850W感度に対して実効Rθ≤100°C/Wが必要となる。
- [Molex PS-43650-001 Rev.N4](https://www.molex.com/content/dam/molex/molex-dot-com/products/automated/en-us/productspecificationpdf/436/43650/PS-43650-001.pdf?inline=): 接触抵抗初期10mΩ最大、圧着部5mΩ最大は低レベル測定。5Aでは接点1個あたり0.25Wという予算になり、駆動の4接点では計1W。高温/経年の保証値ではない。2極W-Bの参考値は18AWG8.5A、20AWG7A、24AWG5.5A、26AWG4.5A。全極通電・30°C温度上昇基準、配線/基板/圧着に依存する。既存の18AWG推奨（短距離20AWG可）を維持し、細い既製ケーブルの外形だけで5A対応としない。対応端子と絶縁外径上限1.85mm、圧着品質も外部配線仕様に含める。

## PWM周波数で変わるD1損失

各エッジで約10µs待つ回路では、その間を還流ダイオードが受け持つ。[Comchip SS54-HF資料](https://www.comchiptech.com/admin/files/product/20190806165140.pdf) の5A時Vf最大0.55V（25°C）を使い、5A一定・両エッジ各11µsという予算を置くと、上限感度 `P_D1=I×Vf×min(1,2f×11µs)` は次となる。11µsは既存LTCの約10.652µs上限計算へ伝播/切替の余裕を置いた設計予算で、全PVT最大保証ではない。

| キャリア | 還流期間の比率 | D1損失・5A一定 |
|---|---:|---:|
| 1kHz | 2.2% | **60.5mW** |
| 5kHz | 11% | 302.5mW |
| 10kHz | 22% | 605mW |
| 20kHz | 44% | **1.210W** |

Vf0.7Vの追加感度では1kHz77mW、20kHz1.54W。実電流減衰や部分Dutyではこれより小さくなり得る。D1の60°C/Wは**50×50mm銅箔**での典型値であり、本基板55×21mmや小さいSMAランドへ転用しない。例として250°C/Wなら1kHz/0.55Vで15.1K、20kHzで302.5Kという差が生じる。後者を許容できるとはしない。

[公式Arduino coreの調査](../pwm-core-research.md)ではmainの既定PWMが1kHzとされるが、実ビルドの版は未固定。**本試作の代表PWM条件は1kHz**とし、20kHzはゲート抵抗の電力予算で使っただけで基板全体の許可キャリアではない。core版/ビルドと実キャリアの確認が必要。周波数を上げる場合はD1損失と最短パルス/有効Dutyを再評価する。

## 熱放散の境界条件を変えた計算

[evaluate_thermal_budget.py](evaluate_thermal_budget.py)/[結果JSON](thermal-budget-results.json) に216通りの一様基板感度、324通りの繰返しブレーキ感度を保存。周囲40°C、Cu温度係数0.00393/K、Q1高温RDS2倍、補助回路0.15W、1kHzを仮定する。補助0.15Wは測定値でもXIAO最大消費電力でもない。放熱は表裏1/2面・対流h=5/10/20W/m²K、ケーブルへの実効熱コンダクタンス0/0.01/0.025W/K、接点熱の基板流入0/50%を振る。

両面h=10、接点熱流入0の例では、35µm/5Aの平衡感度はケーブル放熱0/0.01/0.025W/Kで **98.7/79.2/66.2°C**。70µm感度では **76.9/65.2/57.0°C**。本基板を等温とした結果で、実温度予測ではない。電池側の面が塞がる、配線先が暖かい、モジュール消費が増えるなどで変化する。

同じ両面h=10・35µm・70°Cという解析上限に対し、連続電流はケーブル放熱なしで約3.44A、接点熱50%流入なら約2.86Aまでという感度になる。5Aを一律に無条件認定できないことが、測定を待たず数値で分かる。5Aの成立には実際の放熱/温度条件か銅厚・配線/電力損失の改善が必要。70µmへ変更するだけでも全条件保証にはならない。

Q2は30秒間のブレーキ**指令**を30秒一定5Aと解釈しない。5A初期、電流減衰時定数1/5s、熱137°C/W・熱時定数10sの例では、2s指令/5s周期の周期ピークは周囲40°Cに対し **53.1/76.4°C**、30s指令/40s周期は **45.1/58.8°C**。他部品からの加熱は含まない。5A一定が続く場合は0.850Wとなり、137°C/W単純定常感度で周囲40°Cから約156°Cに達する。実際のモーター減衰・熱時定数は未測定であり、減衰を保証して大電流拘束を許可しない。

## 試作への処置

5Aは設計目標として残し、全条件の連続定格とは宣言しない。最初は1kHz条件・電流制限付き2Aから始め、3.5A、その後に電流/温度を見ながら5A目標へ段階評価する。数秒～数十秒のブレーキ指令を評価するが、一定大電流を時間いっぱい保持する条件と分ける。NTCは遠隔観測で、Q2接合温度や高速故障を自動保護する保証ではない。

今回の机上評価は、PWM周波数の無条件20kHz扱いと理想ビア均等分担への依存を除き、5Aを左右する条件を定量化する。新しいCAD変更は行わず、正規a7aaab20…の出力を保全した。PCBA前の外部受入と、完成基板を必要とする測定を分け、未測定を発注前の循環要件にはしない。
