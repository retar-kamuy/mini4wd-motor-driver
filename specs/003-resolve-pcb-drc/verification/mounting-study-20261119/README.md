# 電池上への着脱固定の検討（2026-11-19）

**第一案は、車体側に固定する耐熱絶縁の開放トレーへ、基板の長辺を浅い爪で保持する方式。** 基板に穴を追加せず、片面PCBAと電池上配置を維持できる。共通の基板保持部と、シャーシ別の脚/取付部を分ける。一般サーキットでの個人使用を対象とし、FM-A/SFM等のフロントモーターは除外する。現物での適合・強度確認を完了したものではない。

## 固定具の具体案

### A：開放トレー＋着脱爪（推奨）

- 電池のラベルへ接着せず、車体の既存取付部または電池保持部へトレーを固定する。電池保持部を使う場合も、本来の電池ロック/取り外し動作を残す。車体固定の脚はシャーシごとに作る。
- PCBのB面を薄い電気絶縁フィルムと数箇所の支持部で受け、F面の部品/パッドに触れない浅い爪で上下・前後・左右を拘束する。片側を固定爪、反対側を解除爪/小ねじ式の押さえとして着脱可能にする。コネクタの外装を固定点にしない。
- 短辺の端止めはコネクタ経路を避けた角付近でPCB端面を受ける。J1/J2中央は開放する。爪/ねじ頭はXIAO、USB、Senseのマイク、電力部品、コネクタロックを塞がない。
- 初期の検討寸法は、内寸55.4～55.6×21.4～21.6mm、外幅約23～24mm。片側0.2～0.3mmの逃げを出発点とし、材料・加工公差で調整する。PCB端の支持量と、押しても外れない掛かり量は別に設計する。
- 支持面からPCB裏面まで約2mmを仮置きする。[Molex公式表の6.98mm級高さ](https://www.molex.com/en-us/products/series-chart/43650)を使うと、`2 + 1.6 + 6.98 + 0.5 ≈ 11.1mm`。**支持面からカウル内側へ11～12mm程度を確認用に確保する案**であり、最高部品/プラグ/配線の全3D照合や公差を保証した値ではない。
- 支持部の間を開放し、裏面や電力部を厚いフォームで全面密閉しない。材料は想定温度で剛性と電気絶縁を維持するものを選ぶ。金属/カーボンのフレームをそのまま絶縁材として扱わない。

基板の爪領域を読取照合できても、シャーシ側の取付穴位置・脚高さはまだ決まらない。この案はPCB穴追加を必須にしないための外付け固定具であり、製造可能なSTL/最終部品表ではない。

### B：薄い絶縁台座＋別体ストラップ（簡易試作向け）

車体に固定した台座の耳をストラップで保持し、ストラップは台座の外側を通す。必要なら小面積の薄い両面テープをガタ取りへ使う。PCB全体を巻いてXIAOやMOSFETへ押し付ける構造にはしない。コネクタ挿抜時の力は本体を手で受け、線材を引いて外さない。熱/繰返し交換による接着の緩みは未確認なので、走行用の主保持を接着だけへ依存させない。

### C：取付穴をPCBへ追加（将来案）

専用ブラケットへねじ固定できるが、穴径・座面・全層銅箔/配線・XIAO下の禁止領域を見直す必要がある。裏面にねじ頭/金属が電池へ近づく構造も評価する。現版へ穴を追加したり、手加工を依頼する案は今回は採用しない。

## 配線・熱・保守

J1=電池、J2=モーターをラベルや配線経路で区別する。片軸後部モーター車ではJ2をモーターへ近づける向きを優先し、太い短い対線を車体/トレー側の別の保持点で支える。線材をプロペラシャフト、ギヤ、タイヤ、電池接点、電池蓋のスライドへ垂らさない。線材/嵌合プラグの寸法と最小曲げ半径は採用品で確認し、62.04mmを配線込み寸法としない。

固定は基板の姿勢を再現できる構造にする。厚い柔らかなフォームはIMUと車体の相対動作を増やすため、ガタ取りを超えた柔軟支持を前提にしない。基板を前後反転する場合はIMU座標/学習条件も合わせる。XIAOのアンテナ周辺を金属部材や束ねた電力線で囲まない。

[5A熱評価](../power-thermal-20261119/README.md)は放熱する面数で結果が変わる。トレー、絶縁材、電池、カウルを装着した状態は、新たな熱境界条件になる。部品の上面を空けても車体で下側を塞げば裸基板の解析条件と同じではない。

**USB保守には独立した干渉懸念がある。** 現XIAOは左向きUSBで、モジュール前面付近x≈9mmとJ1本体右端x≈6.38mmが同じy≈10.5mm軸上、間隔は約2.6mm。通常のUSB-Cケーブル頭部がJ1へ当たる可能性がある。USB/プラグの正確な3D形状・高さは未照合なので断定しないが、トレーから基板を外すだけでJ1との干渉が解消するとも扱わない。基板初回発注前にプラグ形状との照合を行い、必要ならXIAO/コネクタ配置や書込み・保守経路を設計変更案として検討する。

## 試作前にできることと、未確定

先に55×21×1.6mmのダミーと、62.04mmのコネクタ本体投影、採用予定の嵌合プラグ/線材を合わせた簡易治具を車体へ当てれば、電子基板を待たず概略確認できる。確認するのは、カウル装着、電池/モーターカバーの着脱、ロック解除、タイヤ/シャフトとの干渉、両端の線材曲げ、USB経路である。写真の車体全幅やホイールベースだけから隙間を計算しない。

最終の脚位置・爪強度・材料、公差、実装全高さ、嵌合プラグとUSB、実車の隙間は未確定。完成基板では、車体に固定した状態でガタ/ずれ、配線引張り、繰返し交換、低速からの段階走行と温度を確認する。全シャーシの測定や走行試験を試作基板発注前の循環要件にはしない。今回のCAD変更・Git操作・発注・外部送信は行っていない。
