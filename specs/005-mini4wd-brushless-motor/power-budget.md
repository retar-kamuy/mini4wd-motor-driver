# 電源・停止設計の準備 — Spec 005

作成日: 2026-11-20。T014/T016の途中成果。電池・モーター許容値未確認のため数値定格は未確定。

## 電源構成案

電池 → 保護/主電源遮断 → モーター用VM → MCT8316ZR → 三相モーター。
電池から分岐したロジック電源 → USBとの逆流防止経路 → XIAO。
センサー電源 → 必要に応じてスイッチ/レベル変換 → モーターセンサー → 転流IC。

| 項目 | 設計判断 | 確定に必要な根拠 |
|---|---|---|
| 電池セル数 | 1S/2Sをモーター電圧と同一視しない | モーター許容電圧、電流、収納 |
| 1S直結 | MCT8316ZRの最低4.5 Vを満たさない | 1Sなら昇圧または低電圧別IC比較が必要 |
| 2S直結 | 適合不明 | 満充電8.4 Vでモーター定格/最高回転確認 |
| 2S→降圧 | 必要時の比較案 | 効率、最大/過渡電流、回生受入れ、面積 |
| XIAO給電 | 外部電源とUSBの逆流防止を設計 | Seeed回路図、実測ピーク電流、給電端子 |
| センサー給電 | ドライバsleep時の逆給電を防止 | センサー電圧/電流/出力形式 |
| 電流制限 | モーター/電池/配線/ICの最小許容値以下 | ILIM誤差と過渡時間、相電流対電池電流 |
| ブレーキ | 短絡ブレーキとcoastを別制御 | 負荷慣性、熱、母線上昇、保護遮断時 |

[TI MCT8316Z](https://www.ti.com/lit/ds/symlink/mct8316z.pdf)、[Seeed給電ガイド](https://wiki.seeedstudio.com/xiao_mg24_getting_started/)を設計根拠として参照する。XIAOのBAT端子へ2Sを接続しない。内蔵LDOをXIAOの電源として安易に共用せず、ピーク負荷と電源順序を算出する。

## 計算・測定を残す欄

- VM最低/通常/最大、母線サージ、保護遮断電圧。
- 相R/L、相電流RMS/peak、電池電流、拘束時間、許容温度。
- FET導通/スイッチング損失、電源損失、銅箔/熱抵抗と温度上昇。
- 回転体エネルギー `E=Jω²/2`、回生可能な場合のバルク容量目安 `C≥2E/(Vmax²−Vstart²)`。実際のエネルギー分配と電池受入れを別途確認する。
- ヒューズ/遮断素子、逆接対策、TVS/クランプ、バルク容量と配線の電流定格。

値を入れていない式は設計手順であり検証結果ではない。定格未確定のため回路図凍結・通電・製造依頼へ進めない。

2026-11-21: [駆動禁止回路案](hardware-inhibit-design.md)に、独立watchdog、再armラッチ、電源監視、driver側pull-upと許可時だけsinkするDRVOFF駆動を追加した。ロジック電源喪失時の漏れ/逆給電、AVDD立上り、監視閾値、消費電流と実装面積を電源予算に含める。監視部品と抵抗値はまだ未選定。

2026-11-20メーカー資料追跡: [manufacturer-evidence.md](manufacturer-evidence.md)に、取得した京商T05取説、KV/JAN、MZ707=80mm、元車体の単4×4本指定と、取得できなかったセンサー配列/電気定格/寸法を記録した。元車体電源をモーター単体の定格や2S直結適合に換算しない。シャーシ対象は003の範囲（FM-A/SFM等除外）を継承する。


## 2026-11-21 1218S006B基準の電源方向

[公開仕様モーター設計案](documented-motor-design.md)を追加。2S電池から外部buckでVM最大6.0 Vを作り、XIAOロジックは別途給電する方向で比較する。2Sをモーターへ直接接続しない。HallはAVDD由来の許可給電（最大10 mA）。連続値0.663 AはDC-equivalentで、台形転流の相RMS換算0.544 Aを温度条件付き目安とし、peak ILIM値や電池電流へ直接流用しない。通信喪失はcoastとする。電源IC/ILIM/クランプ/熱定数の確定は残る。
