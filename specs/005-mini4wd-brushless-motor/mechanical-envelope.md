# シャーシ収納・軸アダプター測定票

作成日: 2026-11-20。T009–T013の準備資料。測定値はまだない。

## 003から継承する対象範囲

利用者指定により、003と同じくFM-A/SFM等フロントモーターを除く市販シャーシを対象とする。003には単一車種指定がない。AR/VZ等を代表配置として検討し、各車種の実測保証を前提条件にしない。MA/MS/MEの両軸駆動経路への片軸XSPEED適合は別途評価する。根拠とメーカー値は[manufacturer-evidence.md](manufacturer-evidence.md)を参照。

## シャーシ候補の訂正

タミヤ[公式比較表](https://tamiya.com/english/cms/mini4wd_chassis_select.html)ではMA/MSはいずれも両軸モーター中置き。以前のMAを片軸向けとした評価は取り消す。片軸XSPEEDに標準ギヤ経路を活用する場合は後置きのVZ/AR等を先に調べる。AR/VZのメーカー資料で代表配置を評価し、試作後に使用車体のギヤ・カバーとの干渉を確認する。公式の車体外寸は収納可能PCB寸法ではない。

## 測定の基準

完成車の下面水平面をZ基準、前方を+X、左を+Yとし、車軸中心とモーター軸中心を図示する。ノギス/スケールと基準点を写した上/横/下面の写真を紐付ける。寸法ごとに測定器の分解能と誤差を残す。

| 対象 | 必要な値 | 現状 |
|---|---|---|
| シャーシ | 型番、版、ギヤ比、組立カバー | 対象範囲は003を継承。代表配置はAR/VZ、寸法は未取得 |
| モーター缶 | 長さ・幅/径・平面部・固定爪/穴・軸中心 | 未測定 |
| シャフト | 外径を複数方向/位置で測定、突出長、段差 | 未測定 |
| ピニオン | 品番、歯数、穴径、幅、正常な軸方向位置 | 未測定 |
| アダプター | 内外径、公差、肉厚、長さ、締結/保持方法 | 上の測定後に設計 |
| 電池 | 固定材/保護部/配線を含めた最大外形 | 未選定 |
| PCB候補領域 | XY多角形、各領域の上下高さ、取付点 | 未測定 |
| XIAO | USB外向きでプラグ/抜差し/ケーブル曲げ、底面接続高さ | 未測定 |
| 配線 | 相線/センサー線/電源線の経路とコネクタ抜差し空間 | 未測定 |
| 完成状態 | ギヤ/車輪/カバー/路面/アンテナとの最小間隔 | 未測定 |

軸アダプターは利用者指定の解決方法として設計する。寸法と材質がない段階で薄肉スリーブが圧入可能だと決めない。アダプター外径は実際のギヤ穴に合わせ、偏心・軸方向移動・負荷時滑り・最高使用回転での保持を記録する。

## 面積増加の判定方法

最大収納領域と部品配置の両方から、必要面積と増加量を算出する。矩形の面積だけで合否を決めず、端子/放熱銅箔/底面パッド/配線/USB作業空間を加えた配置図で確認する。現段階では必要増加mm²を算定できない。

切削・穴あけ・切断は場所と理由を示す。シャーシ全体の自作へ進む前にVZ/AR等の市販シャーシ比較と配置変更を行う。


## 2026-11-21 専用取付部品の許容と基準モーター

専用取付部品追加を許容するユーザー回答Bに従い、[FAULHABER 1218S006B](documented-motor-design.md)のØ12×18 mm缶と1.2 mm軸を基準に、標準130缶の軸中心を保つホルダー/軸スリーブを検討する。モーター寸法公差と軸突出長は公式図面から取得済み。ギヤ側のピニオン座標・穴径とシャーシ受け部の寸法は別途根拠を取り、専用部品外形を確定する。放熱条件と圧入荷重、路面/カバー干渉を含める。
