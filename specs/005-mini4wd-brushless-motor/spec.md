# Feature Specification: Mini 4WD Brushless Motor

**Feature Branch**: `[005-mini4wd-brushless-motor]`

**Created**: 2026-11-19

**Status**: Ready for planning

**Input**: User description: 「京商 MZ604 XSPEED 85のようにミニ四駆のモータを同じサイズのブラシレスモータで、ミニ四駆を動かせる基板を設計し、PCB製造業者へ製造をお願いしたい。spec 003同様に、PCBの開発を進めたい」

## User Scenarios & Testing

### User Story 1 — ブラシレス化したミニ四駆を走らせる (Priority: P1)

利用者は、対象のミニ四駆に適合する小型ブラシレスモーターと専用制御基板を搭載し、既定の電源・制御装置から操作して走行させる。

**Why this priority**: 走行できることが、この基板開発の中心価値である。

**Independent Test**: 対象車体、選定モーター、規定電源で、停止状態から起動・速度変更・停止までを繰り返し行い、意図した動作と異常の有無を記録する。

**Acceptance Scenarios**:

1. **Given** 対象モーターと承認済み電源を接続した基板が対象車体に搭載されている, **When** 利用者が走行指令を出す, **Then** モーターは意図しない再起動や脱調による停止を起こさず車体を走らせる。
2. **Given** モーターが安定して回転している, **When** 利用者が速度指令を変更または停止指令を出す, **Then** モーターは仕様で定める応答と停止動作を行う。
3. **Given** 電源が仕様で定める動作範囲の端にある, **When** 起動・加速・停止を行う, **Then** 基板は意図しないリセットや制御喪失を起こさない。
4. **Given** 電源・操作信号またはモーター状態に合意済みの異常が発生した, **When** 基板が異常を検出またはその影響を受ける, **Then** 駆動は定めた安全状態へ移り、明示した復帰操作まで意図せず再始動しない。

### User Story 2 — 車体とモーターへ機械的に搭載する (Priority: P1)

利用者は、市販されている既製品のミニ四駆シャーシをベースにし、標準モーター取付部、ギヤ、電池スペースを優先して活用する。必要最小限のシャーシ加工は許容するが、3Dプリンタなどでシャーシ全体を自作する方法は極力避ける。

**Why this priority**: 同サイズ化と車体への搭載が、ミニ四駆で使うための主要な制約である。

**Independent Test**: 対象モーターの寸法・軸・固定方法と、選定した市販シャーシ/ギヤを照合し、標準搭載または必要最小限の加工で組み付けられることを確認する。加工が必要な場合は内容と理由を記録する。

**Acceptance Scenarios**:

1. **Given** 選定した市販シャーシとギヤ, **When** ブラシレスモーターと制御基板を取り付ける, **Then** 標準モーター取付部を優先して利用し、必要なシャーシ加工は最小限に抑えてモーター軸、ピニオン、ギヤ、車体部品が設計上の位置に収まる。
2. **Given** 市販シャーシに車体が組み上がっている, **When** 車輪を手で回し、車体を走行させる, **Then** モーターまたは基板がシャーシ、電池、ギヤ、路面に干渉しない。
3. **Given** 対象候補の市販シャーシ, **When** 標準搭載だけでは適合できない, **Then** 開発者は加工箇所・方法・理由を示し、シャーシ全体の自作を避ける方法を先に評価する。

### User Story 3 — PCB製造業者へ試作を依頼する (Priority: P2)

開発者は、設計版を特定できる製造データと実装資料を揃え、PCB製造業者に試作基板の製造・実装を依頼する。

**Why this priority**: 机上設計を実機評価へ進め、寸法・電気・温度の仮定を試作で検証するためである。

**Independent Test**: 第三者が対象設計版を特定し、製造データ・部品表・配置資料・受入条件を読み取り、見積とDFM回答を返せることを確認する。

**Acceptance Scenarios**:

1. **Given** 固定した回路図・PCBと製造データ一式, **When** 製造業者が受入確認を行う, **Then** 必要な層、穴、部品、向き、特殊工程と要回答事項を特定できる。
2. **Given** 製造業者の見積・DFM回答, **When** 開発者が設計条件と照合する, **Then** 未承認の部品代替や設計変更を含まず、残る製造上の問題と追加費用が明確になる。

### Edge Cases

- リチウム系バッテリーの電圧が起動可能範囲を下回る、走行中に大きく低下する、または過電流・過放電保護が作動する。
- タイヤ拘束、急加速、急停止、ブレーキ、ギヤ噛み込みなどによりモーター電流が増える。
- モーターが低速・停止付近で始動しない、回転方向が異なる、または同期を失う。
- センサー信号、制御信号、電源または基板接続が欠落・不安定になる。
- 車体・電池・ギヤ・配線がモーター、基板、コネクタに干渉し、標準搭載では適合せずシャーシ加工が必要になる。
- 市販シャーシ候補の間でモーター取付部、電池スペース、部品クリアランスが異なる。
- 部品在庫不足、指定モーター/部品のPCBA業者受入不可、組立・検査工程の制約が発生する。
- モーター、駆動部品、基板、電池または配線が許容温度・定格に達する。

## Requirements

### Functional Requirements

- **FR-001**: 設計は、利用者が選定する市販ミニ四駆シャーシをベースに、承認された外形・軸条件を満たす小型ブラシレスモーターで車体を走行させなければならない。シャーシ加工が必要な場合は最小限にし、作業内容と理由を示さなければならない。
- **FR-002**: 設計は、選定したモーター方式に必要な相駆動と回転開始・速度制御を提供しなければならない。
- **FR-003**: 設計は、計画段階で選定するリチウム系バッテリーのセル数、電圧範囲、放電能力の範囲内で起動・駆動・停止を行わなければならない。
- **FR-004**: 操作系は既存のXIAO/BLE・WebAppを第一案として、走行、速度変更、停止およびブレーキ動作を利用できるようにしなければならない。既存方式でブラシレス制御が成立しない場合は、基板内蔵制御器または外部制御器を用いる代替案を比較し、採用前に利用者へ示さなければならない。
- **FR-005**: 設計は、合意した異常条件でモーターまたは基板への損傷を抑え、異常後に安全な状態へ移行しなければならない。
- **FR-006**: 基板・コネクタ・配線は、市販シャーシへの取付、電池交換、ギヤ調整、メンテナンスを妨げてはならない。必要なシャーシ加工は、標準部品の活用とレイアウト調整を検討した後に最小限の範囲で提案しなければならない。
- **FR-007**: 開発成果物は、回路図、PCBデータ、設計ルール、部品表、製造データ、実装座標、組立/検査条件と版識別情報を含まなければならない。
- **FR-008**: 製造業者へ提出する前に、同一設計版について回路図・PCB接続、電気設計規則、製造出力と部品配置を照合しなければならない。
- **FR-009**: 試作後の受入手順は、電流制限付き初回通電、段階的な負荷評価、モーター/基板温度、起動・停止・制御喪失時の挙動を確認できなければならない。
- **FR-010**: 見積・DFM回答では、指定部品の調達/実装、基板製造条件、検査、納期、費用と代替案を明確にし、利用者の承認なしに代替または設計変更を進めてはならない。

### Key Entities

- **ブラシレスモーター**: 外形、取付、軸、相数、センサー方式、電気定格、回転数特性を持つ駆動源。
- **駆動基板**: モーター相を駆動し、電源、操作系、状態監視と異常時動作をつなぐ基板。
- **電源条件**: 電池種類、セル数、電圧範囲、電池・配線の電流能力を表す。
- **操作系**: 走行、速度変更、停止、ブレーキの指令方法と接続条件を表す。
- **車体適合条件**: 対象シャーシ、モーター固定、ピニオン/ギヤ、基板位置、配線とクリアランスを表す。
- **製造パッケージ**: 固定版の回路図、PCB、Gerber/ドリル、BOM、CPL、組立情報、検査条件とハッシュを含む。

## Success Criteria

### Measurable Outcomes

- **SC-001**: 選定した市販シャーシにモーターと基板を組み付けた状態で、未承認の加工がなく、車輪・ギヤ・電池・カバーの干渉が0箇所である。必要な加工は内容と理由が記録され、最小限である。
- **SC-002**: 合意した電圧範囲の最低・公称・最高条件で各10回の起動を行い、意図しない再起動、制御喪失または始動失敗が0回である。
- **SC-003**: 合意した操作条件で、走行・速度変更・停止/ブレーキの各指令が10回中10回、所定の動作結果になる。
- **SC-004**: 市販シャーシを用いた代表走行試験を完了し、電池電圧、電流、基板およびモーター温度が記録され、合意した部品/電池定格を超えない。
- **SC-005**: 製造業者が同一版の製造パッケージを受領し、DFM上の阻害事項または受入条件を回答できる。未回答事項を受入済み扱いにしない。
- **SC-006**: 試作基板を製造し、合意した数量・検査条件で受領できる。実機が必要な未検証項目は試作後の試験記録に分離する。

## Assumptions

- 初期対象は趣味用途のミニ四駆試作であり、複数台量産や競技規則適合の保証を目標にしない。
- 車体は市販の既製品ミニ四駆シャーシをベースにする。初期仕様では計画段階で対象を1種類選び、標準モーター取付部、ギヤ、電池スペースを優先して活用する。必要最小限の切削・穴あけ・切断等は許容するが、加工箇所・理由を記録し、標準搭載や部品選定で回避できないか先に検討する。他の市販シャーシへの互換性は別途確認する。
- 3Dプリンタ等によるシャーシ全体の自作は極力避ける。市販シャーシへの最小限の加工や取付部品の工夫では成立しないと示された場合に限り、代案として検討し、採用前に利用者の承認を得る。
- MZ604は比較例とし、標準的な130サイズのモーター取付部に収まり、メーカーから寸法・電気特性・センサー情報を得られる市販ブラシレスモーターを選ぶ。モーターはセンサー方式を含め、始動性、搭載性、入手性を評価して選定する。京商公式ページはMZ604を8500KVのMINI-Z用ブラシレスモーターとして掲載するが、寸法・電流・電圧の詳細は公開ページに記載されていないため、比較用の参照にとどめる。参考: [京商 MZ604製品ページ](https://rc.kyosho.com/ja/mz604.html)。
- 電源はリチウム系（Li-ionまたはLiPo）を許容し、第一候補として評価する。セル数、容量、電圧範囲、放電能力は、選定モーター・車体搭載可能な電池寸法と電源予算を踏まえて計画段階で確定する。充電器は基板に含めず、バッテリーパックは別体とする。
- 操作・制御は既存のXIAO/BLE・WebAppを優先して再利用する。必要な通信/タイミングと安全性が満たせない場合に限り、基板内蔵制御器または外部制御器を使う構成を比較し、アーキテクチャ確定前に承認を得る。
- 仕様003の既存基板はブラシ付きモーター向けの別設計であり、電源・定格・駆動回路・保護方式を新基板へそのまま流用しない。
- 初回は製造業者へ試作製造を依頼し、完成基板の走行・温度・過渡評価を行う。無条件の電流・温度・モーター互換保証は行わない。
