# データモデル

| エンティティ | 主な項目と関係 |
|---|---|
| 車体構成 | 構成ID、駆動方式、センサー構成、ギヤ比、タイヤ周長、計測校正版、ファームウェア版。各走行が1構成を参照する |
| 走行ログ | 走行ID、車体構成ID、学習・評価の区別、開始レーン、マップ版・適用速度版、時刻付きサンプルとイベント。サンプルは経過時間、加速度、角速度、回転数、品質フラグを持つ |
| 走行イベント | 時刻、周回境界、レーン遷移、位置未確定、速度目標と指令、停止理由。周回時刻は車載推定であることを記録する |
| 区間マップ | マップIDと版、元の学習ログ、開始レーン、全レーン巡回の区間順序。区間はID、レーン、区間種別、推定距離、照合用特徴、次区間との関係を持つ |
| 速度設定 | 設定IDと版、対応するマップ版、各区間の目標速度、位置未確定時の速度上限、状態、適用確認時刻 |
| 比較試験 | 試験ID、同一ブラシレス車の制御無効・制御有効の条件、使用ログ、独立した計時、完走・無効周回・コースアウト、中央値、比較前に定めたばらつきの判定基準 |
| 開発経路・製造記録 | 経路の採否と理由、共通化した成果物、再利用条件と再評価項目。製造記録は基板版、製造資料、調達・実装・検査の回答を関連付ける |

速度設定は **初期案 → 編集済み（任意） → 車体へ適用済み** と進む。適用済みの版を編集する場合は新しい案を作る。車体が受領・検証した版だけを次の走行で使う。マップ版の不一致、区間の不足、許容範囲外の速度がある設定は拒否し、直前の適用済み版を保持する。

時刻は走行開始を原点とする単調増加の経過時間で保存し、単位・座標軸・ログ形式の版を明示する。欠測、空転による距離推定の低信頼、位置未確定を区別する。マップに含まれる区間IDは同一版内で一意とし、レーン遷移を含む全レーン巡回の順序を保持する。各走行の記録は、その時点の版との関連を保持する。
