# 車体とアプリの契約

BLEでアプリを接続し、車体の状態、プロトコル版、適用済みマップ・速度設定の版を読み取る。以下は操作と応答の契約。詳細なバイト形式は実装時に版を付けて決める。

| 操作 | 車体側の条件と応答 |
|---|---|
| 接続・状態取得 | 停止中、学習中、区間別走行中、停止保持を区別する。対応外のプロトコル版では開始要求を拒否する |
| 学習開始 | 停止状態から開始し、走行IDを返す。低速で計測とログを記録する |
| ログ取得 | 停止後に走行ID指定で取得する。分割番号と完了通知により欠落を検出し、欠落したログは学習成功扱いにしない |
| マップと速度設定の適用 | 停止中に、利用者が確認した設定と対応するマップを送る。マップ版、全区間、速度上限を照合し、完全に受領した時点で適用済みの版を返す。転送が中断した場合は直前の版を保持する |
| 区間別走行開始 | 対応版のアプリに接続し、適用済みの組があり、停止状態から明示的な開始要求を受けた場合に限り開始する |
| 接続監視 | 車体は接続喪失または有効な監視応答の期限切れを検出し、駆動を切って自然減速し、停止保持へ移る。単なる再接続で駆動を再開しない |
| 停止 | 停止要求または異常時は車体側で処理し、結果と理由を記録する |

アプリは案と適用済み設定を画面上で区別する。車体は区間とレーンの照合結果、位置未確定、制限中、駆動停止をアプリへ通知する。位置未確定時に適用する速度上限は学習時の上限以下とする。無線の処理やログ転送は車体の停止処理を待たせない。
