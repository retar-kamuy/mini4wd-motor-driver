# Feature Specification: コース適応型ブラシレスミニ四駆

**Feature Branch**: 作業中のブランチは `005-mini4wd-brushless-motor`。作成予定は `006-course-adaptive-mini4wd`。

**Created**: 2026-11-21

**Status**: Ready for planning

**Input**: 005のブラシレス化を土台に、車体だけでコースを学習し、区間に合わせてモーターを制御して通常のミニ四駆より速く完走する。003で経験したXIAOの調達・実装上の制約を踏まえ、専用基板を開発する。ブラシ付き試作の有用性も比較し、採用する場合はブラシレス版への再設計・再評価を抑える。

## User Scenarios & Testing

### User Story 1 — コースを学習する (Priority: P1)

利用者は低速で走らせ、車体で記録した動きと回転数から、直線、カーブ、坂などの順序と周回内のおおよその位置を把握できる。

**Why this priority**: 区間の手前で速度を変えるには、次にどの区間へ入るかを把握する必要がある。

**Independent Test**: コースに機器や目印を追加せず、低速走行から区間マップを作り、別の走行をそのマップと照合する。

**Acceptance Scenarios**:

1. **Given** 未学習の周回コース, **When** 利用者が低速で学習走行する, **Then** 車載計測値と時刻が記録され、周回内の区間順序と推定距離を確認できる。
2. **Given** 保存済みの区間マップ, **When** 同じコースを再走行する, **Then** 車体は記録と現在の計測を照合し、区間または位置未確定の状態を示す。

### User Story 2 — ブラシレス車で周回タイムを縮める (Priority: P1)

利用者は、学習したコースで区間別の速度制御を有効にし、安定して完走しながら通常のミニ四駆より短いタイムを目指す。

**Why this priority**: ブラシレス化とコース学習を、周回タイムで評価する。

**Independent Test**: 同じコースで通常車、区間別制御を無効にしたブラシレス車、有効にした同一ブラシレス車を比較する。

**Acceptance Scenarios**:

1. **Given** 学習済みのコースとブラシレス車, **When** 車体が減速対象の区間に近づく, **Then** 区間に入る前に速度指令を調整し、指令と走行結果を記録する。
2. **Given** 車体が区間を特定できない, **When** 区間に応じた高速指令を出そうとする, **Then** 学習走行以下の速度設定に戻る。
3. **Given** 無線通信で走行を監視している, **When** 走行中に通信を失う, **Then** 駆動を切って自然減速し、通信復帰だけで再始動しない。

### User Story 3 — 開発経路を選び、専用基板を試作する (Priority: P2)

開発者は、ブラシレス版から始める案と、市販ミニ四駆用ブラシ付きモーターで先に試作する案を比較し、短い手戻りで走行評価と製造依頼に進める経路を選ぶ。

**Why this priority**: 先行試作に費やす工数と、ブラシレス版で減らせる手戻りを比較するため。

**Independent Test**: 両経路の評価項目、共通化範囲、移行時の再評価項目を比較し、選定理由を確認する。製造業者が固定した同一版の資料から見積と製造・実装条件を回答できることも確認する。

**Acceptance Scenarios**:

1. **Given** 二つの開発経路, **When** 設計を固定する前に比較する, **Then** 調達、試作工数、先に検証できる機能、移行時の再設計・再評価を記録し、ブラシ付き試作の採否を決める。
2. **Given** ブラシ付き先行試作を選んだ, **When** ブラシレス版へ移行する, **Then** 共通の成果物と試験結果について成立条件を照合し、差分に必要な再評価を特定できる。
3. **Given** 固定した専用基板の設計版, **When** 製造業者が資料を確認する, **Then** 製造条件、部品調達、実装、検査条件を特定し、未解決事項を回答できる。

### Edge Cases

- 似たカーブの繰り返しやレーンチェンジにより、複数の位置候補が残る。
- 空転・ジャンプ・壁との接触により、回転数から推定した距離と実際の移動距離がずれる。
- コースやレーンが変わる、または記録が欠けて、既存マップを信頼できない。
- 電池電圧低下、センサー喪失、制御の再起動により、安全な速度制御を続けられない。
- 指定部品の調達や搭載が難しくなり、製造業者から代替案が提示される。

## Requirements

### Functional Requirements

- **FR-001**: 005を土台に、ブラシレスモーターのセンサー信号で転流する車両と、そのための専用制御基板を開発する。市販シャーシを使い、必要な専用取付部品や最小限の加工を記録する。
- **FR-002**: コース側への目印、機器などの追加を禁止する。車載計測で加速度、角速度、回転数、経過時刻と推定した周回時刻を記録する。区間の識別や位置推定に必要な場合は、車載カメラやその他の追加センサーを使用できる。
- **FR-003**: 記録から区間の順序、区間内の推定距離、周回の境界を含むマップを作成し、次の走行に再利用できるようにする。位置の判定が不確かな場合はその状態を記録する。
- **FR-004**: 車体は現在の計測とマップを照合して区間の手前で速度指令を調整する。利用者は走行後に区間、速度指令と周回タイムを確認できる。
- **FR-005**: 位置を特定できない、またはマップが合わない場合は学習走行以下の速度設定に戻す。通信喪失時には駆動を切って自然減速し、明示的な再操作まで再始動しない。異常時の停止動作は速度最適化より優先する。
- **FR-006**: 詳細設計前に、ブラシレス直行案とブラシ付き先行試作案を、調達、工数、先に検証できる項目、再設計・再評価の範囲で比較し、採否と理由を記録する。
- **FR-007**: ブラシ付き試作を選ぶ場合、車載計測、ログとマップの形式、区間推定、速度指令と安全停止の仕様、制御側の回路と取付方法、試験手順を共通化の対象とする。共通化できない項目には理由を記録する。駆動方式に依存する電源、駆動、ブレーキ、発熱、機構については、移行後の差分と再評価範囲を定める。
- **FR-008**: JLCPCBを第一の製造・実装候補として、部品の入手性と実装可否を設計固定前に確認する。同一設計版の製造データ、部品表、実装座標、検査条件を提出できるようにし、業者の受入条件と未回答事項を記録する。
- **FR-009**: 通常車との比較と、同一ブラシレス車での区間別制御の有効・無効比較を行い、完走・コースアウト・周回タイムを記録する。

### Key Entities

- **走行ログ**: 車載計測値、時刻、区間推定、速度指令、周回結果。
- **区間マップ**: コースとレーンを識別し、区間順序、推定距離、周回の境界を保持する記録。
- **速度設定**: コースの各区間に対応する速度指令と、位置未確定時の設定。
- **比較試験記録**: 車両、電池状態、コース、走行条件、完走数、タイムとそのばらつき。
- **開発経路の決定記録**: 採否、共通設計、再利用する評価とその条件、移行後に再評価する差分。
- **製造パッケージ**: 固定版の製造・実装資料、検査条件、業者回答。

## Success Criteria

### Measurable Outcomes

- **SC-001**: コース側に追加物を設置せず、低速走行で4種類の記録（加速度、角速度、回転数、周回時刻）を取得する。保存後の別走行で、事前に合意した減速対象のうち少なくとも1区間の手前で、速度指令を変更できることを記録で確認する。
- **SC-002**: 同一コースで各条件を有効な計測周回5周以上で比較し、区間別制御を有効にしたブラシレス車の周回タイム中央値が、通常車と同一ブラシレス車の制御無効時の両方を下回る。短縮幅は事前に把握した計測・周回のばらつきを上回り、評価走行のコースアウトは0件とする。失敗や無効周回の件数も記録する。
- **SC-003**: 位置未確定、通信喪失、通信復帰を含む各試験で、定めた速度制限または駆動停止を確認し、意図しない再始動が0件である。
- **SC-004**: 詳細設計前に2案の比較と採否が1件記録される。ブラシ付き試作を行う場合は、各共通成果物・試験に再利用条件を付け、駆動方式の変更に伴う再評価項目を対応付ける。
- **SC-005**: 製造業者へ渡す設計版が1つに特定でき、部品調達、実装、検査に関する回答と未解決事項を追跡できる。

## Assumptions

- 趣味用途の試作を想定する。車体のみで使える区間マップを初期目標とする。試験員による観察・計時を評価に使えるが、それらの情報を走行中の車体へ送る必要はない。
- 車載カメラや追加センサーは任意とする。採否は、区間の識別や位置推定の改善と、車体への搭載性、重量、消費電力を比較して設計計画で決める。
- 通常車は、代表的な市販ミニ四駆を通常のブラシ付きモーター、指定の電池、通常の駆動で走らせる比較車とする。同じコース、レーンまたはレーン巡回条件、スタート条件で比較する。モーター・ギヤ比、タイヤ、車重、電池状態と走行順を事前に記録する。ブラシレス車の制御有効・無効の比較には同一車体と同一の電源・駆動条件を使う。
- 003はブラシ付き駆動の参考、005はブラシレス駆動と市販シャーシへの搭載の参考とする。制御アプリと専用基板はCodexが設計する。具体的なデバイス、電池、回転計測方式、共通回路の構成は設計計画で選定する。
